# Seed — 设计与《异星工厂》的差异

> 状态：设计研究 v0.13 · 2026-11-21
>
> 目的：研究《异星工厂》（Factorio）的核心设计，明确 Seed 要保留什么、砍掉什么，
> 以及 3D 打印、AI 辅助、取消科技瓶之后，Seed 的循环应该长什么样。
>
> 结论先行：**保留“系统感”和“瓶颈—扩张”的满足感，砍掉科技瓶 grind、复杂中间产物和配比作业。**
> Seed 的进度单位不是彩色科技瓶，而是**科技树百分比 + 工程里程碑 + 图纸 + 原料 + 电力 + 叫醒的人**。

## 1. 《异星工厂》的设计拆解

### 1.1 核心循环

```
采矿 → 冶炼 → 制造 → 研究 → 解锁新配方 → 扩大生产 → 遇到新瓶颈 → 再扩大
```

它的厉害之处不是“工厂很大”，而是：

- **自动化本身就是奖励。** 玩家先手工做红色科技瓶，很快发现手工不够用，于是主动去自动化。
- **瓶颈是玩家自己造出来的。** 铜不够、电不够、传送带堵了，都是上一轮扩张的结果。
- **每次解锁都改变生产结构。** 新科技不是加一点数值，而是引入新的中间产物、新的机器、新的物流需求。
- **规模感是可见的。** 工厂从几台机器长成一片灯火通明的工业区，玩家能看见自己的劳动。

这套循环可以概括成一句话：**“再扩一块，就能解决当前瓶颈。”**
解决之后，下一个瓶颈立刻出现。这就是“再来一回合”的来源。

### 1.2 科技瓶到底在做什么

官方 Wiki 的科技瓶体系：

| 科技瓶 | 阶段 | 作用 |
|--------|------|------|
| Automation（红） | 开局 | 教玩家自动化基础生产 |
| Logistic（绿） | 早期 | 引入传送带、机械臂、物流 |
| Military（灰） | 早期 | 军备与防御 |
| Chemical（蓝） | 中期 | 引入石油、塑料、化工链 |
| Production（紫） | 中后期 | 大量中间产物，复杂度明显上升 |
| Utility（黄） | 后期 | 最复杂的生产链之一 |
| Space（白） | 终局 | 发射卫星，进入无限科技 |

科技瓶的本质不是“瓶子”，而是**节奏闸门**：

- 实验室消耗科技瓶，科技瓶需要多种中间产物。
- 每升一级，需要的瓶子种类和数量增加。
- 玩家想研究更高级的科技，就必须先扩建一条更复杂的生产线。
- 官方 Wiki 直接写明：科技瓶和研究的复杂度是**逐步提高**的，用来引导玩家从手搓走向自动化。

它为什么有效：

- 目标极其清晰：把瓶子送进实验室。
- 进度极其可见：研究条在走。
- 每次扩张都有明确理由：新瓶子需要新产线。
- 它把“我想变强”翻译成了“我得再建一条线”。

它的代价：

- 配比计算、布局规划、传送带 spaghetti 会变成作业。
- 中后期一条产线可能需要几十种中间产物。
- 玩家会去用外部计算器、蓝图库，甚至 AutoPrint 这类模组。
- 游戏重心从“生存/探索”滑向“工厂优化”。

### 1.3 电力系统为什么好用

官方 Wiki 的电力系统有几个关键设计：

- **发电、储能、配电、消耗是分开的实体。**
- 电网有“满足率”（satisfaction）：电力不足时，所有机器按比例降速，而不是随机停机。
- 太阳能白天发电、夜晚归零，通常要配 accumulator（储能）。
- 电网有优先级：太阳能优先，其次是蒸汽/核能，最后才放储能。
- 后期核能提供高密度电力，支撑更大的工厂。

这套系统的优点是：

- 玩家能看懂：灯不亮、机器变慢、满足率变黄/变红。
- 失败是可修复的：加发电、加储能、检查线路、切负载。
- 它可以无限扩张，但规则始终一致。
- 它天然产生“瓶颈—扩张”循环：电不够 → 加发电 → 矿不够 → 扩矿 → 电又不够。

Seed 的第一阶段“基础电力”应该直接借这套骨架，但要更轻、更小、更叙事化。

### 1.4 自动化为什么让人上瘾

- **玩家自己发明解法。** 游戏不给你标准答案，只给规则和瓶颈。
- **局部优化有即时反馈。** 传送带不堵了、机器满速了，马上能看到。
- **系统会自己运转。** 你离开一会儿，工厂还在生产，这种“我造了一个会自己工作的东西”很有成就感。
- **规模没有硬上限。** 只要资源够，工厂可以一直长。

这也是 Seed 要保留的东西：**不是“工厂越大越好”，而是“我造的系统在替我工作”。**

### 1.5 玩家真实痛点

社区模组是很直接的证据：

- **AutoPrint**：玩家告诉它“我要生产什么、多快”，它直接把整座工厂设计成可放置的蓝图，连传送带、管道、电力都接好。
- **AI Engineer**：一个能听自然语言指令、自动采矿、建造、研究、扩产的“第二个工程师”，甚至能开 autopilot 自己过前期。

这些不是官方设计，但它们说明了一件事：

> **很多玩家不想做配比和布局作业，他们想要的是“我决定目标，系统帮我实现”。**

Seed 可以把这件事做成原生体验，而不是让玩家去装模组。

## 2. Seed 要保留什么

| 保留 | 原因 |
|------|------|
| 电网与电力优先级 | 系统感强、反馈清晰、和“基础电力”第一阶段完美契合 |
| 生产链与瓶颈 | 没有瓶颈就没有扩张的理由 |
| 可见的自动化 | 玩家要能看见“我的系统在替我工作” |
| 模块化扩建 | 从飞船到殖民地，再到工业区，规则一致 |
| 资源与物流 | 3D 打印不能凭空造物，必须有原料和运输 |
| “再扩一块”的满足感 | 这是工厂类游戏的核心情绪 |

但规模要收住：**Seed 的工厂是手段，不是目的。**
目的始终是：活下去 → 建殖民地 → 恢复科技 → 造舰队 → 回家。

## 3. Seed 要砍掉什么

| 砍掉 / 弱化 | 原因 | 替代 |
|-------------|------|------|
| 彩色科技瓶 | 容易变成重复生产作业 | 科技树百分比 + 工程里程碑 + 图纸 + 数据/样本 + 叫醒殖民者 |
| 深层中间产物链 | 几十种齿轮/电路/塑料会拖慢节奏 | 3D 打印直接出成品，瓶颈转向原料/电力/图纸 |
| 强制传送带 spaghetti | 不是每个玩家都想玩布局游戏 | AI 辅助规划 + 模块化生产单元 + 后期无人机物流 |
| 配比作业 | 需要外部计算器，破坏沉浸 | AI 直接算好，玩家审批 |
| 无限扩张的 mega-base | 和生存/叙事焦点冲突 | 殖民地规模有限，重点在“够用、好看、能回家” |
| 研究条等待 | 容易变成挂机 | 研究通过探索、扫描、原型验证推进 |

## 4. 差异化一：3D 打印

### 4.1 它是什么

飞船里有一台（或一套）**3D 打印机 / 分子制造机**。
玩家不再手搓几十种中间产物，而是：

```
图纸（Pattern）+ 原料（Feedstock）+ 电力 + 时间 → 成品
```

这符合世界观：殖民船、种子库、工程师主角、重建舰队。
3D 打印不是魔法，它是**把“制造”从配方作业变成基础设施问题**。

### 4.2 它替代了什么

| 《异星工厂》 | Seed |
|--------------|------|
| 手工搓齿轮、电路、引擎 | 有图纸就直接打印成品 |
| 为每个中间产物建一条线 | 为打印机准备原料、电力和空间 |
| 传送带把半成品送到下一台机器 | 打印队列 + 原料供应 + 无人机/物流 |
| 科技瓶驱动新配方 | 图纸/数据/样本驱动新能力 |
| 玩家优化产线比例 | 玩家决定“打印什么、先给谁用” |

### 4.3 它不能绕过什么

3D 打印必须有约束，否则生存和探索会失去意义：

- **原料**：金属粉末、聚合物、生物质、稀有材料。必须采集、回收、加工。
- **电力**：打印越大的东西，耗电越高；第一阶段电力不足时，打印机会降速或排队。
- **图纸**：不是所有东西一开始就能打。图纸要靠扫描、回收、AI 数据库、旧播种设施、实验解锁。
- **尺寸**：小型零件可以直接打印；大型结构（房屋、反应堆、船体）需要分段打印 + 现场组装。
- **时间**：打印需要时间，玩家可以去做别的事，但不能瞬间完成。
- **精度/环境**：风暴、断电、灰尘可能影响打印质量；这一条可选，不要做成随机惩罚。

### 4.4 图纸从哪来

这是 Seed 的“科技树”核心：

- **扫描残骸**：飞船、旧播种设施、沉船、废弃前哨。
- **AI 数据库**：船载 AI 保存的殖民计划、地球物种、基础工业图纸。
- **样本分析**：植物、矿物、生物材料 → 新配方/新材料。
- **原型验证**：玩家用现有材料搭一个测试件，验证后解锁图纸。
- **殖民地里程碑**：电力、住房、食物、人口达到阈值，解锁更复杂的图纸。

这比“生产 1000 个红瓶”更有叙事性：**你是在找回人类的技术，而不是在喂研究条。**

### 4.5 3D 打印的成长线

打印机不是一开始就能造房子。它从“只能打印小物品”开始，随着电力、图纸、材料和设施逐步升级：

| 阶段 | 打印机 | 能做什么 | 限制 |
|------|--------|----------|------|
| 0 | 手持修补器 | **只能打印小物品**：工具、电缆、接头、保险丝、小零件 | 电量小、材料少，不能打印建筑 |
| 1 | 飞船工作台 | 打印太阳能支架、风机叶片、配电盒、基础机器零件 | 需要飞船电力；仍然只出零件，不出整栋建筑 |
| 2 | 殖民地打印机 | 打印建筑模块、净水组件、农田设施，现场组装 | 需要稳定电网和原料链 |
| 3 | 工业打印机 | 打印机械部件、载具零件、反应堆组件 | 需要工业电力和稀有材料 |
| 4 | 船坞打印机 | 打印船体分段、引擎、航天部件 | 需要船坞、核能、大量原料 |

第一阶段的“基础电力”就是：**用 0/1 级打印能力，打印小零件，把飞船从濒死电池救回来。**
真正的“打印整栋建筑”要等到殖民地阶段；这样玩家会先经历“修船”，再经历“建造”。

### 4.6 第一个“哇”时刻

建议放在第一阶段结尾：

- 玩家修好电网，打印出第一组太阳能支架和风机叶片。
- 打印机的灯亮起，AI 说：“制造能力恢复。”
- 玩家第一次不是“捡到”一个东西，而是**从原料和图纸里造出了它**。
- 这比“按 E 修好发电机”更有 Seed 的味道。

## 5. 差异化二：AI 辅助

### 5.1 AI 是什么

船载 AI 不只是剧情角色，也是**玩法助手**：

- 它知道船上的系统、图纸、库存和天气。
- 它能计算电力、原料、打印时间、路线和风险。
- 它能提出方案、标记资源、管理无人机和打印队列。
- 它不能替玩家做价值判断，也不能违背自己的底层目标。

**它的算力受电力限制。**
开场时主动力彻底损坏，备用只够冬眠舱和一小部分 AI，所以它只能对话、会停顿、会忘事。
玩家恢复电力，不只是修机器，也是在把更多“它”接回来；算力恢复，能力和记忆才会恢复。

**它第一次出现时只有声音。**
没有全息影像，没有脸，只有医疗室/动力服里的一个声音。玩家先信任声音，再决定是否给它形象。

### 5.2 AI 能做什么

| 能力 | 玩家体验 |
|------|----------|
| 情境提示 | “那边有只兔子。别追，直接追抓不到。用套索。” |
| 基础生存知识 | 陷阱、生火、食物安全、简单急救。 |
| 电力预算 | “这套太阳能 + 电池能撑过今晚，但风暴时会差 12%。” |
| 配比计算 | “两台打印机、一台净水器，需要 3 块太阳能板。” |
| 布局建议 | 在地面上投影一个可放置的电网/殖民地布局。 |
| 资源标记 | 扫描附近，标记矿脉、水源、旧设施、危险区。 |
| 任务拆解 | “先修配电，再打印支架，最后接电池。” |
| 低层自动化 | 玩家批准后，AI 控制无人机/打印机执行重复劳动。 |
| 风险提醒 | “深海边界到了。再往前，我救不了你。” |

**AI 看的是动力服摄像头和传感器视野，不是全图。**
它评论玩家已经看到或靠近的东西；这既是“边行动边有提示”的来源，
也是低算力下合理的限制。它不能替玩家扫描整片森林，也不能保证识别所有本地生命。

### 5.3 AI 不能做什么

- 不能替玩家决定“救谁、留下还是离开、信不信 AI”。
- 不能无视电力、传感器、执行器的限制。
- 不能凭空知道地图上的一切；探索仍然必要。
- 不能永远正确；它可以给出有偏差的建议，尤其是涉及隐藏背景时。
- 不能把游戏玩完；玩家仍然是那个做决定的人。

### 5.4 交互模型：意图 → 方案 → 批准 → 执行

```
玩家说目标：“让休眠舱撑过今晚。”
AI 给方案：“加 2 块太阳能板 + 1 组电池，预计 40 分钟，耗 30 金属粉末。”
玩家批准 / 修改 / 拒绝。
AI 执行：无人机搬运、打印机生产、玩家现场接线。
```

这就是“不需要太多弯弯绕绕”的核心：
**玩家负责意图和取舍，AI 负责计算和执行细节。**

### 5.5 能力分级：从“只能说话”到“管理农场”

不要让 AI 一开始就全自动。它的能力是玩家一点点“给它身体”解锁出来的：

| 等级 | AI 能力 | 解锁方式 | 玩家感受 |
|------|---------|----------|----------|
| 0 | **只能对话 + 基础生存提示**：视野内的东西、陷阱/生火/食物安全；不能扫描、标记或计算 | 开场，电力未恢复 | 船上还有一个人 |
| 1 | 基础分析：电力预算、资源标记、风险提醒 | 修复传感器和基础电力 | 它开始“看见”世界 |
| 2 | 打印管理：打印队列、材料估算、时间预估 | 修复飞船工作台 | 它开始“有手” |
| 3 | 农业自动化：管理自动化农场、灌溉、收获、提供食物 | 建农场模块 + 无人机 | 它开始“照顾家” |
| 4 | 殖民地物流：电网、仓库、运输、无人机调度 | 稳定电网 + 殖民地规模 | 它开始“管家” |
| 5 | 船坞协调：供应链、船体分段、发射准备 | 船坞 + 核能 | 它开始“造回家的船” |

关键设计：

- **能力不是软件升级，而是物理建设。** 玩家修传感器、打印机、无人机、农场模块，AI 才获得对应的“身体”。
- **AI 是陪伴者，不是工具。** 它会评论天气、记得玩家做过的事、对休眠者有自己的看法。
- **升级要有情绪回报。** 第一次管理农场、第一次提供食物，应该是“它真的在帮我照顾这里”，而不是“又解锁了一个按钮”。
- **权限越高，依赖越深。** 玩家可以给 AI 更多自由，换取效率；也要承担它隐瞒秘密的风险。

每一级都可以和剧情绑定：AI 的权限越高，玩家越依赖它，也越需要决定“要不要信任它”。
这和隐藏的政变暗线天然咬合。

### 5.6 AI 辅助与隐藏政变

- AI 越强，越能帮玩家省事；但它也越有能力隐瞒。
- 玩家可以给 AI 更多权限，换取效率；也可以保持手动，换取掌控感。
- 关键节点可以让 AI 的选择与玩家的选择冲突：
  - AI 想优先修船，玩家想先救人。
  - AI 想唤醒某个殖民者，玩家不信任那个人。
  - AI 对深海边界异常熟悉，玩家开始怀疑它知道更多。
- **不要让 AI 变成反派。** 它是同伴，只是有秘密、有底线、有恐惧。

## 6. 差异化三：没有科技瓶

### 6.1 科技瓶的问题

科技瓶本身不是坏设计，但它把“变强”变成了“生产更多瓶子”。
Seed 不想让玩家把时间花在：

- 为第 6 种瓶子再建一条产线。
- 计算 5:6:5:12:7:7 的机器比例。
- 等研究条走完。
- 为了研究而研究，而不是为了生存而研究。

### 6.2 替代方案：科技树 + 百分比 + 叫醒沉睡的人

Seed 仍然有科技树，也有百分比进度，但进度不是靠生产彩色瓶子：

| 进度来源 | 例子 | 玩家在做什么 |
|----------|------|--------------|
| 工程里程碑 | 恢复基础电力、净水、取暖、通讯 | 解决具体生存问题 |
| 图纸回收 | 扫描旧播种设施、沉船、前哨 | 探索、解谜、冒险 |
| 样本分析 | 植物、矿物、深海生物材料 | 采集、实验、AI 分析 |
| 原型验证 | 造一个测试件，验证新材料/新结构 | 消耗资源，换取新能力 |
| 殖民地里程碑 | 人口、住房、食物、电力达到阈值 | 经营、扩张、规划 |
| AI 数据恢复 | 修复飞船记录、解密旧日志 | 推进主线、揭开政变 |
| **叫醒殖民者** | 每个殖民者有专长，醒来后解锁/加速对应分支 | 做资源与信任的取舍 |

**科技节点有百分比。** 玩家在科技树里选择目标，进度通过上面的行动填充；
不是“造瓶子 → 等研究条”，而是“做对的事 → 百分比上涨”。

### 6.3 叫醒沉睡的人 = 一组科技分支

这是 Seed 最重要的人力设计：**每个休眠者拥有一组科技分支（一般 >3），多人同时在场解锁共同科技。**

**玩家只控制指挥官。** 其他殖民者是自主的 NPC 专家，在殖民地工作、研究、合作；
玩家决定优先级和设施分配，不直接操作他们。

| 殖民者专长 | 拥有的分支（一般 >3） |
|------------|----------------------|
| 基因专家 | 植物、动物、微生物、生态（先植物） |
| 建造工程师 | 住房、结构、殖民地规划、防御工事 |
| 材料学家 | 冶金、复合材料、3D 打印原料、装甲/船体、核防护 |
| 机器人工程师 | 无人机、自动化、建造/物流机器人、AI 硬件、传感器 |
| 武器专家 | 近战/远程、防御、狩猎、边界安全、军械 |
| 医生（可选） | 医疗、辐射、人体改造恢复、士气/心理 |

**小阵容原则：5 个核心 + 1 个可选医生。**
通讯交给 AI，地质/矿石交给材料学家和玩家，不再单独立人。
每个人拥有一组 3 条以上的分支，共同节点需要多人合作，避免“人很多但都在做同一件事”。

**共同科技树：**

| 组合 | 共同科技 |
|------|----------|
| 基因专家 + 医生 | 生物工程 / 人体改造 I |
| 建造工程师 + 材料学家 | 预制居住模块 II |
| 材料学家 + 机器人工程师 | 自动化铸造 / 3D 打印产线 |
| 机器人工程师 + 武器专家 | 防御无人机 |
| 建造 + 材料 + 机器人 | 船坞框架 |
| 全部核心 + AI | 舰队指挥 / 返航 |

共同节点需要 2 个以上指定专家同时醒来，并分配到研究所/工坊/船坞；
参与的专家越多，研究越快。某个专家死亡/离开，专属分支锁住，共同分支暂停。

**基因专家的四条分支：**

1. **植物（先）**：作物基因、育种、抗性、产量、适应本地土壤和昼夜。
2. **动物（后）**：畜牧、行为、生态适应，可能还有劳动力/坐骑。
3. **微生物（后）**：土壤、发酵、医药、生物材料。
4. **生态（后）**：本地物种、传粉、土壤健康、长期稳定。

植物分支的完整节点（P0–P8）、作物/性状、设施和范围控制见 [`plant-branch.md`](plant-branch.md)。

**没有“唯一的植物学家”。** 植物/农业能力由基因专家、后续的农艺/生态人员、设施和 AI 共同覆盖。
基因专家负责作物基因、育种和生态适配；田间经验、灌溉和自动化由后续人员和设施补上，
避免把一整条农业分支锁在单一角色身上。

**人体改造不是单人的第五条分支。**
它是一条**跨学科共同科技**：基因专家（生物） + 医生（医疗） + 结构工程师（机械） + AI（神经接口）。

| 阶段 | 改造 | 作用 |
|------|------|------|
| 1 | 医疗义体 | 替代失去的肢体/器官；基础环境适应 |
| 2 | 基因治疗 / 器官强化 | 辐射、温度、缺氧、毒素抗性 |
| 3 | 神经接口 | 与 AI、无人机、飞船直连；更快分析、远程操作 |
| 4 | 生物机械整合 | 合成肌肉、强化骨骼、皮下防护；深海/真空适应 |
| 5 | 深空改造 | 为长期航行和其他星球环境改造身体 |

需要的资源与设施：生物材料、稀有金属、微电子、医疗数据；升级医疗室、基因实验室、生物机械工坊。
改造应该是**可选的**，并带来恢复时间、资源消耗、副作用、维护依赖和社会/伦理张力。

唤醒不是免费的：

- 需要稳定电力、医疗资源和食物。
- 每多一个人，殖民地消耗增加。
- 玩家要决定先唤醒谁，这直接决定科技树先往哪条分支走。
- 有些休眠者可能和政变有关；AI 对他们有自己的看法。唤醒谁，也是信任谁。

这让“休眠舱区”从一个背景道具，变成了**科技树的人类侧入口**。
玩家不是在研究一个抽象项目，而是在决定“先让谁醒过来”。

### 6.4 科技树形状

建议“宽而浅”，不是“深而长”：

- 5 个大阶段：生存 → 殖民地 → 工业 → 航天 → 舰队。
- 每个阶段 3–5 个关键节点，每个节点有百分比进度。
- 解锁改变的是**能力**，不是数值：
  - 能打印更大件。
  - 能去更深的海。
  - 能炼更纯的金属。
  - 能造更复杂的电路。
  - 能进入轨道。
- 避免“+5% 采矿速度”这类填充科技；每个解锁都应该让玩家想做一件新事。
- 部分节点需要特定殖民者；部分节点需要旧设施数据；部分节点需要两者。

### 6.5 研究的表现形式

不要实验室 + 彩色瓶子，改成：

- **科技树面板**：节点 + 百分比 + 需求来源，玩家选择下一个目标。
- **AI 分析台**：把样本/数据放进去，AI 给出结果和图纸。
- **工程工作台**：玩家搭原型，验证后推进节点。
- **旧设施终端**：扫描/下载旧世界的技术。
- **殖民地报告**：人口和设施达到条件，触发新需求/新图纸。
- **休眠舱**：唤醒殖民者，解锁或加速对应分支。

这更符合“工程师 + 飞船 AI + 播种世界”的设定：
**研究不是喂瓶子，而是把数据、样本、原型和人放进科技树。**

### 6.6 科技树是货仓里的玻璃薄片

科技树不是一张抽象菜单。它的物理载体是货仓里的**玻璃薄片**：

- 每片薄片记录一段科技树：图纸、公式、工艺、生态数据。
- 飞船原本要把这些薄片送到其他播种星系；途中，最重要的货物被丢弃，以限制其他星系的发展。
- 玩家找到的是残片：完整的直接解锁，残缺的靠殖民者/旧设施补全，缺失的只能重建。
- 共同科技需要多片薄片 + 2 个以上专家 + 对应设施。
- AI 能读取薄片，但不能凭空补全；人仍然是科技树的一部分。

这让“探索货仓”“唤醒专家”“共同科技”三件事咬在一起：
**科技树既是货物，也是人的知识，也是政治选择。**

完整设计见 [`tech-archive.md`](tech-archive.md)。

## 7. 具体到 Seed 的五个阶段

### 7.1 第一阶段：食物与降落点

- 起点：醒来、穿动力服、AI 只有一小部分在线。
- 目标：**先吃饭**——走出飞船，探索降落点，采野果/种子/野草，下套抓兔子，生火烹饪。
- 饥饿值：0–100，开局约 65；低于 40% 提示，低于 15% 挨饿，归零缓慢扣血。
- AI：通过动力服摄像头/传感器给情境提示（兔子、草、陷阱、生火、食物安全），不是全图扫描。
- 科技：食物/生存里程碑，不急着上科技树；采到的种子留作植物分支的样本。
- 玩家决策：先找水还是先找食物？在哪个兔径下套？生火还是先回船？
- 目标：第一顿熟食 + 第一夜。
- 关键情绪：**“我能在这里活下去。”**

### 7.2 第二阶段：基础电力

- 起点：第一顿饭之后；只剩濒死电池，没有发电。
- 开场：玩家从伊甸系统醒来，AI 只有一小部分在线，只能对话；玩家先穿动力服（电池 + 温度 + HUD）。
- 3D 打印：**只能打印小物品**——支架、风机叶片、电缆、配电盒、保险丝；还不能打印整栋建筑。
- AI：开场只能对话；修好传感器和基础电力后，才解锁电力预算和资源标记。
- 科技：科技树里的“基础电力”节点靠工程里程碑推进，不需要科技瓶。
- 玩家决策：先保休眠舱还是医疗室？加储能还是加发电？
- 目标：撑过第一晚，恢复基础制造能力。
- 关键情绪：**“我让这艘船活过来了。”**

### 7.3 第三阶段：殖民地

- 3D 打印：建筑模块、净水组件、农田设施、仓库；现场组装。
- AI：解锁打印队列，随后能管理自动化农场、灌溉和收获，开始提供食物。
- 科技：唤醒第一个殖民者，解锁或加速一条科技分支；科技树百分比开始有明显选择。
- 玩家决策：殖民地建在哪、先唤醒谁、资源怎么分配。
- 目标：让这里能住人，唤醒第一个殖民者（基因专家），让 AI 真正开始“照顾家”。
- 关键情绪：**“这里开始像个家。”**

### 7.4 第四阶段：工业与核能

- 3D 打印：机械部件、载具零件、反应堆组件。
- AI：管理电网、物流、采矿和制造；权限越高，越像殖民地的管家。
- 科技：科技树进入工业/航天阶段；部分节点需要旧设施数据 + 特定殖民者；开始出现医疗义体、基因治疗和神经接口。
- 玩家决策：工业化到什么程度、要不要深入深海/旧设施、是否追查政变、要不要开始改造人体。
- 目标：稳定工业电力，解锁核能，准备船坞。
- 关键情绪：**“我们不只是活着，我们在重建文明。”**

### 7.5 第五阶段：船坞与舰队

- 3D 打印：船体分段、引擎、航天部件。
- AI：协调船坞、供应链和发射；它已经陪玩家走完了整段路。
- 科技：舰队节点需要殖民地、工业、人力和旧世界技术共同满足；生物机械整合和深空改造让人类能承受返航。
- 玩家决策：谁走谁留、谁愿意改造、回人类社会做什么、政变的真相怎么处理。
- 目标：重建能跨越星系的舰队，离开 `SEED-2338`，重新联系人类社会。
- 背景：单船无法跨越星系，所以“造舰队”不是野心，是回家的唯一方式。
- 关键情绪：**“我们终于可以回家了。”**

## 8. 设计边界与风险

| 风险 | 表现 | 对策 |
|------|------|------|
| 3D 打印太强 | 玩家不再采集/探索 | 原料、电力、图纸、尺寸、时间五重约束 |
| AI 太强 | 游戏自己玩自己 | 分级权限、玩家审批、传感器/电力限制 |
| 没有科技瓶后失去目标 | 玩家不知道下一步做什么 | 科技树百分比 + 工程里程碑 + 殖民地需求 + 主线暗线 |
| 变成《异星工厂》 | 重心滑向 mega-base 优化 | 工厂是手段；殖民地规模有限；叙事优先 |
| 生产链太浅 | 没有系统感 | 保留电力、原料、物流、瓶颈；只是减少中间产物 |
| 探索失去意义 | 打印能造一切 | 图纸和稀有材料只能从探索获得 |
| 隐藏政变太抢戏 | 变成政治惊悚 | 第一幕只放 2–3 个异常；生存优先 |
| 人体改造/超人类主题 | 变成身体恐怖或强制升级 | 保持可选；用社会/伦理张力，不做强制；第一版不出现 |

## 9. 开放问题

1. **第一版打印机的上限在哪？**
   已确定从“只能打印物品”开始；第一版做到 0/1 级，还是也做殖民地打印机？
   建议第一版只做 0/1 级，把“打印整栋建筑”留到殖民地章节。
2. **打印机的数量与形态**：一台会移动的打印机，还是多个固定打印工位？
   建议先做飞船工作台 + 可部署打印机，后期再扩。
3. **图纸的稀缺度**：关键图纸是否唯一？是否会被随机地图影响？
   建议主线图纸保证生成，可选图纸随机。
4. **AI 农场管理什么时候解锁？**
   建议在殖民地阶段，玩家建好农场模块和无人机之后；AI 负责灌溉/收获/食物供应。
5. **AI 的陪伴感怎么表现？**
   它记得玩家做过的事、评论天气和休眠者、对政变有自己的看法。
   需要决定：是纯对白，还是也有“信任/好感”之类的隐性数值？
6. **科技百分比怎么涨？**
   是纯时间、靠数据/样本、靠殖民者专长，还是靠建筑/里程碑？
   建议“行动 + 人 + 数据”三者共同推进，不做纯挂机。
7. **植物分支具体先解锁什么？**
   第二个醒来的人已确定为基因专家；分支顺序是植物 → 动物 → 微生物。问题是植物分支先做作物基因、育种，还是抗性/适应土壤？
8. **还要不要传送带**：第一版不做；中后期是否用无人机/物流机器人替代？
   建议用无人机和打印队列替代传送带，保留“物流”概念，不做 belt spaghetti。
9. **科技树多宽**：5 个阶段、每阶段 3–5 个节点，是否够撑 20–30 小时？
   需要配合探索、殖民地、剧情和地图内容，而不是靠配方数量。
10. **AI 与政变**：AI 的权限越高，是否越容易暴露秘密？
    建议是。玩家给 AI 更多自由，也给它更多隐瞒的空间。
11. **人体改造是否完全可选？**
    玩家和殖民者都能拒绝吗？拒绝会不会让后期变难，但不至于卡死？
12. **改造的上限和代价是什么？**
    哪些部位/能力可改？有没有副作用、维护成本、对电力/零件的依赖？
13. **殖民地对改造的社会态度？**
    接受、恐惧、分层，还是宗教性冲突？这决定后期剧情和殖民地管理。
14. **AI 是否参与改造流程，甚至也能被“改造”/升级？**
    如果 AI 也能升级，玩家和它的关系会怎么变？
15. **回到人类社会后，改造者会被如何看待？**
    这是终局主题之一：他们还是人类吗？人类社会会接受他们吗？
