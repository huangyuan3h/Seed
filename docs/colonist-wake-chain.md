# Seed — 同伴唤醒链

> 状态：设计草案 + 灰盒实现 v0.6 · 2026-11-21
>
> 定位：第一幕末到第二幕初的核心推进链。
> 目标：把“食物 → 庇护 → 电力 → 唤醒同伴 → 研究所 → 种地”串成一条玩家能理解、能执行的路径。
> v0.7 变更：明确可唤醒核心队员都是可靠小队成员；政变参与者不在小队里，悬疑转向过去/AI/真相。
>
> 关联文档：[`first-phase-food.md`](first-phase-food.md) · [`plant-branch.md`](plant-branch.md) · [`tech-archive.md`](tech-archive.md) · [`cast.md`](cast.md) · [`story.md`](story.md)

## 1. 一句话

每个休眠者都不是按 E 就醒。他们需要**电力、食物、庇护、医疗/设施**的不同组合；
玩家要先把这个“家”准备到能接住一个人的程度。

## 2. 玩家与 NPC 的边界

- **玩家只控制指挥官**，不能切换到其他殖民者。
- 其他殖民者是**自主的 NPC 专家**，在殖民地生活、工作、研究。
- 玩家决定优先级、分配设施、批准研究；NPC 专家负责执行和推进他们自己的分支。
- AI 是助手，不是殖民者；它可以分析、建议、管理自动化，但不拥有科技分支。

这样“唤醒谁”才有意义：你不是多一个可操作角色，而是多一个会自己工作的专家，
以及他能带来的**一组科技分支**。

## 3. 完整链条

```
食物循环（野果 / 兔子 / 熟食）
→ 简易房屋（庇护 + 存粮）
→ 热能发电机（木材/生物质燃料）
→ 给飞船充电
→ AI 提示：可以尝试唤醒基因专家
→ 唤醒基因专家（电力 + 食物 + 庇护 + 医疗）
→ 建研究所
→ 研究本地植物 / 作物基因
→ 解锁简单种地（P0–P2）
```

### 为什么先热能发电机

- 太阳能/风能需要时间搭建，前期没有稳定电网。
- 热能发电机是**启动电源**：烧木材/生物质/燃料，给飞船电容充电。
- 它不需要很多电，只需要“够唤醒一个人”。
- 太阳能/风能是之后的**稳定电网**；核能是后期。

**热能发电机不是最终方案，是让飞船从“濒死电池”变成“能再叫醒一个人”的第一步。**

## 4. 基因专家的唤醒条件

| 条件 | 要求 | 说明 |
|------|------|------|
| 热能发电机 | 已建造 | 前期启动电源 |
| 飞船充电 | 电力 ≥ 20 | “不多”，够唤醒一个人 |
| 简易房屋 | 已建造 | 有屋顶、床/休息处、存粮空间 |
| 食物储备 | ≥ 10 份 | 够基因专家醒来后吃几天 |
| 医疗室 | 可用 | 唤醒后的基本医疗保障 |

满足后，AI 提示：

> “我们有屋顶，有存粮，飞船也充上电了。可以试试唤醒基因专家——他们说不定能理解这里的植物。”

唤醒不是瞬间完成：需要一段恢复时间，基因专家醒来后先是虚弱状态。

## 5. 每个同伴的不同需求

每个殖民者的电力/食物/设施需求不同。数值先占位，后面用 `colonists.json` 数据驱动。

| 同伴 | 电力 | 食物 | 庇护 | 额外设施 | 拥有的分支（一般 >3） |
|------|------|------|------|----------|----------------------|
| 基因专家 **Sana Ahn** | 20 | 10 | 简易房屋 | 医疗室 | 植物、动物、微生物、生态（4） |
| 建造工程师 **Tomas Rook** | 30 | 15 | 简易房屋 | 工坊 | 住房、结构、殖民地规划、防御工事（4） |
| 材料学家 **Lin Qiao** | 40 | 15 | 简易房屋 | 熔炉 / 材料实验室 | 冶金、复合材料、3D 打印原料、装甲/船体、核防护（5） |
| 机器人工程师 **Juno Park** | 50 | 20 | 简易房屋 | 机器人工坊 / 无人机巢 | 无人机、自动化、建造/物流机器人、AI 硬件、传感器（5） |
| 武器专家 **Vale**（失踪） | 50 | 20 | 简易房屋 | 军械库 | 近战/远程、防御、狩猎、边界安全、军械（5） |
| 医生 **Yusuf Erdem**（可选） | 40 | 15 | 简易房屋 | 医疗室升级 | 医疗、辐射、人体改造恢复、士气/心理（4） |

**Vale 就是 07 号舱的安全官。** 她的舱是空的，所以武器/防御分支暂时锁死；
玩家需要先找到她，才能解锁军械库和边界科技。人物设定见 [`cast.md`](cast.md)。

**小阵容原则：5 个核心 + 1 个可选医生。**
通讯交给 AI，地质/矿石交给材料学家和玩家，不再单独立人。
每个同伴不是“一个节点”，而是**一组 3 条以上的分支**：

- **基因专家**：食物、生物、生态。
- **建造工程师**：房子、殖民地、结构。
- **材料学家**：材料、3D 打印、装甲、船体。
- **机器人工程师**：无人机、自动化、AI 硬件。
- **武器专家**：防御、狩猎、边界。
- **医生（可选）**：医疗、辐射、人体改造恢复。

这样 5–6 个人就能覆盖整条科技树，不会变成“几十个 NPC 排队等唤醒”。
玩家是指挥官，负责优先级和资源；NPC 专家负责推进各自的分支。

### 共同科技树

两个或多个专家同时在场、并且被分配到对应设施时，解锁**共同科技节点**：

| 组合 | 共同科技 | 作用 |
|------|----------|------|
| 基因专家 + 医生 | 生物工程 / 人体改造 I | 基因治疗、器官强化、改造恢复 |
| 建造工程师 + 材料学家 | 预制居住模块 II | 更强、更大的殖民地建筑 |
| 材料学家 + 机器人工程师 | 自动化铸造 / 3D 打印产线 | 批量材料、自动制造 |
| 机器人工程师 + 武器专家 | 防御无人机 | 边界/基地防御 |
| 建造 + 材料 + 机器人 | 船坞框架 | 大型船体、装配线 |
| 全部核心 + AI | 舰队指挥 / 继续任务 | 终局舰队与跨星系航行 |

合作规则：

- 专属节点：只有对应专家能推进。
- 共同节点：需要 2 个以上指定专家**同时醒来**，并且分配到研究所/工坊/船坞。
- 研究速度：参与的专家越多、设施越好，百分比涨得越快。
- 玩家不直接操作 NPC，只决定“谁去哪个设施、先研究什么”。
- 某个专家死亡/离开，他的专属分支会锁住；共同分支会暂停，直到找到替代或恢复。

原则：

- 越往后，电力/食物/设施要求越高。
- 有些同伴需要特定设施（研究所、医疗室、工坊、材料实验室、机器人工坊、军械库）。
- 唤醒谁、什么时候唤醒，是资源和信任的选择。
- **核心队员都是可靠的 squad members**；政变是过去的事，参与者不在可唤醒小队里。
- 他们的冲突是专业/性格/旧怨，不是背叛；悬疑留在过去、AI 和真相处理。
- 医生是可选第 6 人；如果不做医生，基础医疗由医疗室 + AI + 基因专家覆盖。

## 6. 研究所与植物研究

基因专家醒来后，不能立刻种地。需要：

1. **研究所**：电力、材料、空间；可以先用飞船工作台/3D 打印件搭一个简易版。
2. **样本**：玩家在降落点采到的野果/种子/草穗，是第一批材料。
3. **植物研究**：P0 种子库调查 → P1 温室 → P2 主粮作物。
4. **简单种地**：解锁第一块农田/温室，能种主粮和快熟作物。

研究所不是装饰建筑，它是**基因专家的“工作台”**：
没有它，基因专家只能聊天和看样本；有了它，科技树百分比才开始涨。

研究所也可以读取货仓里的**植物玻璃薄片**：
有薄片时，P0 起步更快；没有薄片时，基因专家只能从零研究，速度更慢。
这解释了为什么“探索货仓”和“唤醒基因专家”要一起做。完整设计见 [`tech-archive.md`](tech-archive.md)。

## 7. AI 提示节点

| 条件 | AI 提示 |
|------|---------|
| 有简易房屋 + 食物接近 10 | “我们有屋顶了。再存一点食物，就能考虑唤醒基因专家。” |
| 热能发电机建成 | “发电机在给飞船充电。再等一会儿，电力就够唤醒一个人。” |
| 电力 ≥ 20 | “飞船有足够的电了。只差庇护和存粮。” |
| 所有条件满足 | “可以试试唤醒基因专家——他们说不定能理解这里的植物。” |
| 基因专家醒来 | “基因专家醒了。他们需要研究所才能开始研究这里的植物。” |
| 研究所建成 | “研究所上线。现在可以让基因专家研究本地植物了。” |

提示不重复，不刷屏；只在条件变化时出现。

## 8. 数据表建议

`data/content/colonists.json` + `colonists.schema.json`：

```json
{
  "id": "geneticist",
  "display_name": "Geneticist",
  "role": "geneticist",
  "pod_id": "geneticist_pod",
  "required_power": 20.0,
  "required_food": 10,
  "requires_shelter": true,
  "requires_medbay": true,
  "requires_lab": false,
  "owned_branches": ["plant", "animal", "microbe", "ecology"],
  "wake_dialogue": "geneticist_wake"
}
```

字段：

- `required_power`：唤醒时需要的最低电力。
- `required_food`：库存食物数量。
- `requires_shelter` / `requires_medbay` / `requires_lab`：设施门槛。
- `owned_branches`：这个专家拥有的科技分支（一般 >3）。
- `wake_dialogue`：唤醒演出/对白。

共同科技节点建议放在 `tech.json` 里，用 `owners: ["geneticist", "doctor"]` 表示需要哪些专家同时在场。
完整的 owner id、`shared` / `min_owners` / `fallback_owners` 规则和 82 个节点见 [`tech-tree.md`](tech-tree.md)。

## 9. 第一版范围（灰盒已实现）

第一版**不实现完整唤醒链**，但已经把以下内容放进场景：

- 一个**锁定的基因专家休眠舱**：`scenes/world/geneticist_pod.tscn`。
- 交互时显示当前条件：热能发电机、电力、房屋、食物、医疗室。
- 条件满足时，AI 给出“可以尝试唤醒”的提示。
- 需求检查：`scripts/colony/colonist_pod.gd` 的 `can_wake()` / `requirements_summary()`。
- 测试覆盖：初始锁定、条件满足后解锁。

当前需要的标记（还没有系统去设置它们）：

| 标记 | 由谁设置 |
|------|----------|
| `thermal_generator_built` | 未来的热能发电机建造系统 |
| `power_capacity` | 未来的电力系统 |
| `shelter_built` | 未来的简易房屋建造系统 |
| `medbay_online` | 未来的医疗室/电力系统 |

实际的唤醒演出、研究所、种地留到后续。
这样玩家能看到下一阶段的目标，而不是只有一个空休眠舱。

## 10. 开放问题

1. 热能发电机烧什么：木材、生物质、燃料，还是三者？
2. 热能发电机是一次性充电，还是持续发电？
3. 唤醒基因专家需要多久？玩家要等，还是做别的事？
4. 唤醒失败/中断会怎样？
5. 研究所是独立建筑，还是飞船里的一个工作台升级？
6. 简单种地先做温室还是露天田？
7. 同伴唤醒顺序是否会影响政变线？
8. 食物储备计数：只算野果，还是算所有食物？
