# Seed — 基因专家：植物分支

> 状态：设计草案 v0.5 · 2026-11-21
>
> 定位：第二幕（殖民地）开始的核心科技分支，不是第一版 vertical slice 的内容。
> 主角：第二个醒来的人——**基因专家**（NPC 专家，玩家不直接控制）。
> 目标：把“能种活”变成“能养活殖民地”，再变成“能在这颗星球上长期稳定”。
> v0.5 变更：货仓植物薄片可加速 P0；没有薄片也能从零研究，但更慢。
>
> 关联文档：[`story.md`](story.md) · [`design.md`](design.md) · [`tech-archive.md`](tech-archive.md)

## 1. 一句话

植物分支不是“种地”，而是**把一座种子库、一颗陌生星球和一群饿着的人接在一起**。

> 基因专家有四条分支：**植物、动物、微生物、生态**。本文只展开植物分支；
> P8 是生态分支的接口。玩家只控制指挥官，基因专家是 NPC 专家，负责推进这些分支。

## 2. 设计支柱

1. **先吃饱**：热量、营养、储存，优先于漂亮的花园。
2. **适应而不是征服**：地球作物要适应本地土壤、昼夜、气候和微生物。
3. **基因是进度**：每个节点解锁一种能力，不是加 5% 产量。
4. **看得见的成长**：温室 → 农田 → 生态带，殖民地真的变绿。
5. **失败可管理**：病害、霜冻、干旱、土壤耗尽，都是可应对的麻烦，不是全灭。

## 3. 分支结构

```
P0 种子库调查
  → P1 温室
    → P2 主粮作物
      → P3 土壤改良
        → P4 作物基因 I
          → P5 露天农业
            → P6 抗逆作物
              → P7 生物材料与药用植物
                → P8 生态整合
```

- 前 3 个节点（P0–P2）是第二幕的“吃饭线”，必须跑通。
- P3–P6 是“扩张线”，让殖民地从小温室走向农田和更多地貌。
- P7–P8 是“后期线”，把植物接入 3D 打印、医疗和生态稳定。
- 动物/微生物分支从 P3 开始产生交叉，但不需要等它们才能吃饭。

## 5. 每个节点的具体设计

### P0 种子库调查

**玩家在做什么：**

- 进入种子库，检查冷藏单元、种子批号、地球作物样本。
- 在研究所/基因实验室分析 3 批种子。
- 采集本地土壤和植物样本，和 AI 的气候数据对照。

**前置：** 基因专家醒来后，先建研究所；没有研究所，P0 不能开始，也不能解锁简单种地。

**货仓薄片：** 如果玩家在货仓找到植物相关的玻璃薄片，P0 可以直接获得一部分基础进度；
没有薄片也能从零研究，但慢得多。见 [`tech-archive.md`](tech-archive.md)。

**第一阶段的野生种子：**
玩家在降落点采到的野果/种子/草穗不是白采的——它们是 P0 的第一批本地样本。
基因专家醒来后不用从零开始；玩家已经替他/她踩过点、带回过材料。

**关键问题：**

- 哪些地球作物还能发芽？
- 本地土壤缺什么？
- 哪些本地植物可食、可药用、或者有毒？

**奖励：**

- 作物目录（codex）。
- 温室图纸。
- 第一块可种植的土壤配方。

**叙事：**

基因专家第一次进入种子库，看到“地球带来的全部家当”。
这不是抽象科技，是一排排可能再也回不去的故乡作物。

### P1 温室

**玩家在做什么：**

- 用 3D 打印件搭温室框架、玻璃/膜、温控和灌溉。
- 接电、接水。
- 种下第一批测试作物。

**关键选择：**

- 温室建在飞船旁边（安全、供电方便）还是靠近水源（灌溉方便）？
- 先种快熟作物（ morale / 新鲜食物）还是主粮（长期热量）？

**奖励：**

- 第一批新鲜食物。
- 殖民地士气上升。
- 温控/灌溉系统解锁。

**叙事：**

第一株绿芽是“这里能活”的第一个证据。
AI 可能会说一句很轻的：“它们真的长出来了。”

### P2 主粮作物

**玩家在做什么：**

- 选择主粮：土豆、大豆、小麦/水稻类似物，取决于种子库存和气候。
- 播种、浇水、除虫、收获、储存。
- 建立基础轮作，避免土壤耗尽。

**关键选择：**

- 产量 vs 营养 vs 抗性。
- 先喂饱大家，还是先存粮应对坏季节。

**奖励：**

- 稳定食物来源。
- 食物储存设施。
- 殖民地可以开始接收更多醒来的人。

**叙事：**

第一次收获不是胜利，而是“今晚不用算着口粮过日子”。

### P3 土壤改良

**玩家在做什么：**

- 建堆肥设施，处理作物残渣和有机废物。
- 采集本地土壤/微生物样本，测试肥力和 pH。
- 用堆肥/灌溉改良一块田。

**关键选择：**

- 用地球微生物改良土壤，还是先观察本地微生物？
- 是否接受“改造土壤”的伦理代价？

**奖励：**

- 堆肥、灌溉、土壤健康。
- 产量上升。
- 为微生物分支埋线。

### P4 作物基因 I

**玩家在做什么：**

- 在基因实验室测序作物。
- 选择第一个性状：产量、抗病、耐储存、营养。
- 造一个原型，做田间试验。

**关键选择：**

- 先追求产量，还是先追求稳定？
- 是否让基因专家冒风险做更激进的改造？

**奖励：**

- 第一个作物性状。
- 种子工程能力。
- 基因实验室升级。

**叙事：**

这是第一次“主动改造生命”。
基因专家可能会有短暂的不安：他们是在帮作物适应，还是在替它做决定？

### P5 露天农业

**玩家在做什么：**

- 清理土地、翻土、修灌溉渠。
- 把温室里的作物移到露天。
- 建立轮作、生物防虫、防风林。

**关键选择：**

- 在哪些地貌开田：河边、平原、火山灰土？
- 是否为了农田砍伐本地植被？

**奖励：**

- 农田地块。
- 规模农业。
- 剩余食物可用于交易/储备。

### P6 抗逆作物

**玩家在做什么：**

- 从山地/海岸/极端环境采集样本。
- 做胁迫测试：冷、旱、盐、UV。
- 编辑作物，让它们能在更苛刻的地貌生长。

**关键选择：**

- 改造地球作物，还是驯化本地作物？
- 抗逆性状会不会带来生态风险？

**奖励：**

- 耐寒/耐旱/耐盐/抗 UV 作物。
- 可以在更多 biome 建立农场。
- 为深海/高地/火山带殖民地做食物准备。

### P7 生物材料与药用植物

**玩家在做什么：**

- 种植纤维作物、药用植物。
- 建加工设施，提取纤维、生物塑料、药物成分。
- 把植物材料接入 3D 打印和医疗。

**关键选择：**

- 先做建材/纤维，还是先做药？
- 是否用基因改造提高药用成分？

**奖励：**

- 植物纤维 → 3D 打印原料。
- 生物塑料 → 包装/零件。
- 药用植物 → 医疗资源。
- 纺织品 → 殖民地生活质量。

### P8 生态整合

**玩家在做什么：**

- 建传粉者栖息地、本地树篱、防风林。
- 让地球作物和本地生态形成稳定关系。
- 观察一整季，确认没有生态崩溃。

**关键选择：**

- 继续扩张农田，还是留出生态缓冲？
- 本地物种是合作伙伴，还是竞争者？

**奖励：**

- 减少病虫害/天气损失。
- 本地作物/药材。
- 殖民地长期稳定。
- 主题收束：**人类不是把地球复制过来，而是学会和这颗星球一起生长。**

## 6. 作物与性状

### 作物类型（建议）

| 类型 | 例子 | 作用 |
|------|------|------|
| 主粮 | 土豆、大豆、小麦/水稻类似物 | 热量、储存 |
| 快熟 | 生菜、萝卜、香草 | 新鲜食物、士气 |
| 蛋白 | 豆类 | 营养、土壤固氮 |
| 纤维 | 亚麻/麻类 | 3D 打印原料、纺织品 |
| 药用 | 本地/地球药用植物 | 医疗 |
| 本地 | 待定 | 生态整合、未知风险 |

### 性状（建议）

- 产量 +、抗病 +、耐储存 +、营养 +。
- 耐寒、耐旱、耐盐、抗 UV。
- 固氮、深根、快速生长。
- 药用成分、纤维强度、生物塑料产率。

> 不建议做“每个作物一棵独立科技树”。用“作物类型 + 性状”组合，控制内容量。

## 8. 与其他分支的关系

| 分支 | 关系 |
|------|------|
| 微生物 | 土壤改良、发酵、药物；P3/P8 可加速 |
| 动物 | 饲料、粪肥、传粉/劳动力；植物分支提供基础 |
| 人体改造 | 植物纤维/生物塑料/药物 → 医疗义体、生物机械 |
| 3D 打印 | 植物纤维/生物塑料 → 打印原料 |
| AI | 气候数据、样本分析、自动化农场 |
| 电力/水 | 温室、灌溉、加工的前置 |

## 9. 基因专家的角色

- 第二个醒来的人；玩家之后第一个殖民者。
- 专业：植物基因、育种、生态适配；不是“唯一的植物学家”。
- 性格方向（待定）：
  - 谨慎：先观察，再改造。
  - 激进：为了活下去，什么都愿意试。
  - 怀旧：想种出地球的味道。
- 个人目标：让殖民地吃上一顿像家的饭。
- 与 AI 的关系：AI 提供数据和模拟，基因专家提供判断和手感。
- 与政变的关系：可选。种子库可能被动过手脚，某些种子缺失；这是后期线索。

## 10. UI / UX

- **科技树**：植物分支节点 + 百分比；显示前置、进度来源、解锁。
- **基因实验室**：样本槽、性状选择、测序进度、原型按钮。
- **农场面板**：作物、土壤、水、光照、健康、收获。
- **作物图鉴**：已发现作物/性状/本地植物。
- **AI 建议**：AI 可以推荐“先种什么”“哪块地适合什么”，但玩家决定。

## 11. 范围控制

第一版不做植物分支；第一版只做**基础电力 + 第一夜**。

第二幕先做：

- P0 种子库调查
- P1 温室
- P2 主粮作物

跑通“基因专家醒来 → 温室 → 第一顿饭”之后，再扩 P3–P8。

不做：

- 每个作物一棵独立科技树。
- 复杂的基因编辑器（先做“选性状 + 原型”）。
- 大规模农业自动化（AI 农场管理到后期再开）。
- 真实农业模拟（光照/CO2/授粉细节）。

## 12. 开放问题

1. 作物用真实地球作物，还是虚构名字？
2. 第一个主粮是什么：土豆、大豆，还是别的？
3. 基因编辑 UI 做到多深：选性状，还是拼基因？
4. 病害/虫害/霜冻做到什么程度：随机事件，还是可预测的系统？
5. 本地生态的伦理线要不要做重？
6. 基因专家叫什么、什么性格、是否和政变有关？
7. 食物质量要不要影响殖民者士气/健康？
8. P3/P8 是否强依赖微生物分支，还是可以单线跑通？
