# Seed — 美术方向 / Art Direction

> 状态：v0.1 · 2026-11-21
>
> 范围：3D 场景、角色、道具、材质、灯光、UI 的统一视觉语言。
> 依据：`story.md` §4/§5（类地生态、半埋飞船、应急灯、藤蔓）、`opening.md`（花园揭示）。
> 原则：**先服务可读性与叙事，再谈精度。** 这是风格化写实，不是照片写实。

## 1. 一句话

> **一座被森林慢慢吞掉的白色种子飞船，和一群刚从冰里醒来的人。**

画面要同时有“人类工程的冷”和“类地生态的暖”。冷的是船体、舱门、休眠舱、应急灯；
暖的是草、树、晨雾、土壤、篝火。玩家每次从飞船走向野外，都应该是从冷到暖的一次呼吸。

## 2. 视觉支柱

| 支柱 | 含义 | 落地 |
|------|------|------|
| **半埋的巨物** | 飞船必须大到看不全，永远有一个“还有更多”的方向 | 远处 60–120 m 的船体剪影、断裂环、藤蔓、雾 |
| **自然的回收** | 植物已经在接管人造物，而不是“干净的科幻场景” | 船体底部草坡、锈迹、苔藓、藤蔓、积水 |
| **可读的生存信号** | 每一类交互物有一眼可认的颜色和轮廓 | 食物=莓红，木材=暖棕，纤维=黄绿，电力=冰蓝，危险/异常=锈红 |
| **低多边形、软边缘** | 造型简化，靠轮廓、色块和光来读，而不是贴图细节 | 平直着色、少量三角面、倒角、柔和阴影 |
| **晨光与长影** | 默认时间是清晨/傍晚，低角度阳光、长阴影、薄雾 | 太阳高度 15–25°，暖色主光，冷色天光 |

**用色规则**

- 世界保持低饱和；只有交互物、灯光和 UI 允许高饱和。
- 蓝色 = 还有电 / AI 在线；琥珀 = 可用 / 需要玩家注意；红色 = 损坏 / 异常 / 危险。
- 不用纯黑和纯白：最暗用 `#141A1A`，最亮用 `#EDE8DC`。

## 4. 造型语言

| 类别 | 形状 | 细节 |
|------|------|------|
| 飞船 / 舱体 | 胶囊、圆角盒、断裂的环 | 倒角、面板缝、外露管线；底部永远有土和草 |
| 殖民建筑 | 方、坡顶、临时支撑 | 木/纤维/金属混搭，能看出“手工搭的” |
| 自然物 | 圆锥、球簇、细长三角 | 树冠不追求真实，追求剪影；草用交叉薄片 |
| 交互物 | 比环境亮 10–20%，带微弱自发光或轮廓光 | 玩家 20 m 外也能识别 |
| 角色 | 小头、宽肩、外骨骼关节 | 动力服是“能看出机械结构”的软硬混合 |

**比例**

- 玩家 1.7 m；休眠舱 2.2 m 高；棚屋 2.4 m 高；树 5–12 m；船体环直径 60–90 m。
- 所有网格在 Blender 里按 **1 unit = 1 m** 制作，导出 glTF 时应用缩放。
- 交互物在 0.8–2.0 m 高度区间，避免被草挡住。

## 5. 灯光与大气

- **主光**：暖白 `#FFE8C8`，能量 1.2–1.5，阴影开，阴影距离 120 m，柔和。
- **天光**：冷青 `#8FB4C4`，天空环境光，能量 0.5–0.7。
- **雾**：高度雾 + 距离雾，颜色 `#AEBDB4`，让 60 m 外的山和船退后。
- **辉光**：只让 emissive > 1 的灯光溢出（应急灯、舱灯、打印头），阈值 1.0，强度 0.35。
- **AO**：SSAO 开，半径 1.0，强度 1.4，负责让草和船体贴地。
- **色调映射**：ACES，轻微提高对比和饱和（contrast 1.03 / saturation 1.05）。
- **默认时间**：清晨。太阳高度 18°，长阴影，草上有露水感（靠材质粗糙度和高光）。
- **昼夜**：`SeedEnvironment` 跟随 `WorldTime` 驱动太阳/月亮弧线、天空色、雾色和环境光；夜晚自动打开玩家的头灯。

## 6. 材质规则

| 材质 | 粗糙度 | 金属度 | 说明 |
|------|--------|--------|------|
| 船体陶瓷 | 0.55–0.7 | 0.0 | 微微泛光，不掉漆到发亮 |
| 氧化金属 | 0.45–0.6 | 0.6–0.8 | 有磨损，不用镜面 |
| 舱窗玻璃 | 0.1–0.2 | 0.2 | 深色底 + emissive，不透明更省事 |
| 岩石 | 0.95 | 0.0 | 平直着色 |
| 植物 | 0.85–0.95 | 0.0 | 顶点色 + 轻微风摆 |
| 土壤/草 | 0.95 | 0.0 | 顶点色 + 世界空间噪声，避免平铺感 |
| 木材 | 0.9 | 0.0 | 暖棕，不用木纹贴图 |

**不做的**

- 不做 PBR 贴图堆细节；靠顶点色、平直着色、灯光和雾。
- 不做写实人脸；角色保持低多边形和头盔/兜帽。
- 不做高饱和“外星荧光”整体色调；异星感来自生态和巨物，不来自颜色噪声。

## 7. UI

- 沿用 `gu_core` 的 Protoss 主题：细线、深色半透明面板、等宽/大写字距。
- 强调色从琥珀 `#E08A3C` 和冰蓝 `#79C7D8` 中选一个，当前用琥珀作文本高亮，冰蓝作系统状态。
- HUD 只显示“现在要做什么”：饥饿、交互提示、AI 字幕。
- 按钮不圆润；4 px 圆角、1 px 描边，像飞船的物理面板。
- 标题画面用一张叙事主视觉，文字压暗，不做满屏渐变。

## 8. 资产管线

```
assets/
  art/            key art, UI backgrounds
  art/icons/      generated item icons (256 px PNG)
  models/         .glb / .fbx + LICENSE
  models/seed/    generated low-poly kit
  shaders/        sky, terrain, foliage, water
  materials/      shared .tres (optional)
tools/blender/    headless generator + preview renders
```

- **命名**：`snake_case`，带类别前缀：`env_tree_a.glb`、`prop_pod_07.glb`、`char_settler.glb`。
- **单位**：1 m；原点在脚底/地面接触点；Y-up；朝向 +Z。
- **导出**：glTF 2.0（`.glb`），应用修改器，三角化，材质用顶点色或简单 PBR。
- **预算**：单个小道具 < 2k tri；树 < 1.5k；角色 < 8k；场景靠 MultiMesh 复用。
- **导入**：`.import` 不提交（见 `.gitignore`），由 `gu check` 的 `godot-import` 重新生成。
- **第三方**：必须带 `LICENSE.txt`（当前使用 Quaternius CC0 人物）。

### 8.1 程序化资产工具

`tools/blender/build_seed_assets.py` 用无头 Blender 5.2 从色板和尺寸直接生成
`.glb`、物品图标和评审渲染图：

```bash
blender -b --factory-startup --python tools/blender/build_seed_assets.py
```

- 单一数据源：`PALETTE` 色表 + 每个资产的 `build_*()` 函数。
- 自动满足 §4 比例、§6 材质和 §8 导入约定（1 m、脚底原点、+Z 朝向、平直着色）。
- 每次生成 `docs/art/asset_kit_preview.png` 和 `docs/art/icon_sheet.png`，便于对比。
- 生成结果目前**只在资产库中，尚未替换场景里的程序化占位**。
- 详细用法见 [`tools/blender/README.md`](../tools/blender/README.md)。
