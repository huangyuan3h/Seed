# Seed — 开场分镜：第一次呼吸

> 状态：演出草案 v0.10 · 2026-11-21
>
> 范围：从黑屏到玩家第一次走出休眠区，约 7–9 分钟。
> 目标：在不堆世界观的前提下，完成“我是谁 → 我在哪 → 我为什么必须找吃的 → 我能做什么”的闭环。
> v0.10 变更：加入 0.4c/40 光年/100 年航程；飞船物理携带种子、移民、知识；玩家睡过了大部分航程。
>
> 开场地只是飞船的**最外层**：休眠舱区、医疗室、船体破口。能量舱、货仓、舰桥和科技树薄片都在后面。
>
> 关联文档：[`story.md`](story.md) · [`design.md`](design.md)

## 1. 情绪曲线

```
黑暗 / 迷茫 → 听见一个声音 → 确认自己是谁 → 穿上动力服 → 看见其他沉睡的人
→ 发现飞船已死 → 打印第一个零件 → 走出舱门，看见准备好的星球 → 决定让船活过来
```

玩家弧线：**“我是谁？” → “我能站起来。” → “我能修好它。”**
AI 弧线：**抱歉 → 务实 → 保护 → 一点希望。**

开场不解释政变，不解释伊甸的全部真相，也不解释 `SEED-2338` 的历史。
只给玩家三件事：**一个声音、一副身体、一个必须现在做的任务。**

## 2. 角色与声音

| 角色 | 呈现 | 备注 |
|------|------|------|
| 玩家 / 指挥官 | 第一人称舱内视角 → 第三人称 | 名字和性别在开场确认 |
| 船载 AI | **Mira / 米拉**，只有声音，没有全息影像 | 低算力，句子短，偶尔停顿；当前对白 speaker 仍是 `Ship AI`，显示名后续迁移 |
| 飞船 | 环境音与灯光 | 半埋、断电、应急灯、金属应力 |
| 其他休眠者 | 休眠舱里的剪影 | 不说话，但存在感要强 |

AI 的声音设计：

- 近场、干净、略压缩，像戴在耳边的通讯。
- 低算力时有轻微断续、尾音被吃掉；恢复电力后逐渐稳定。
- 不卖惨，不机械朗读；它是在努力保持礼貌和镇定。
- 称呼玩家“指挥官”；确认名字后可以叫名字，正式场合仍用“指挥官”。

## 4. 逐拍细写

### 拍 0：黑屏（0:00–0:20）

- **画面**：全黑。极暗的霜纹在屏幕边缘缓慢生长，像隔着一层结冰的玻璃。
- **声音**：低频船体嗡鸣；液体从舱体里被抽走；一声很轻的心跳；螺栓松开。
- **AI**：“很抱歉把你叫醒，指挥官。”
- **节奏**：说完停 2 秒，让玩家以为还有下文，再进入画面。
- **目的**：先建立“有人在跟你说话”，而不是先给一个陌生的世界。

### 拍 1：舱内第一人称（0:20–0:50）

- **画面**：霜和雾气慢慢退去。模糊的 HUD 亮起：心率、体温、氧气、`EDEN // WAKE`。
  应急灯在头顶闪，舱盖内壁有冷凝水。
- **声音**：舱体泄压；HUD 启动音；AI 的声音有轻微断续。
- **AI**：“你刚刚从伊甸系统里醒来，记忆还有些缺失。”
- **玩家**：第一次获得控制，只能小幅转头。
- **目的**：让玩家先“看”，再“动”；把记忆缺失和画面模糊绑定。

### 拍 2：身份确认（0:50–1:30）

- **画面**：舱内医疗屏亮起，出现简洁的身份确认界面。
  不是“创建角色”菜单，而是“休眠后身份校验”。
- **声音**：按键音；AI 的声音靠近，像在耳边。
- **AI**：“但我不得不这样做——我们的动力系统彻底损坏了。”
- **AI**：“休眠会造成身份漂移。请确认你的名字和性别，指挥官。”
- **玩家**：输入名字、选择性别。确认后，HUD 显示名字。
- **AI**：“确认。欢迎回来，指挥官。”
  （如果对白系统支持占位符，可用“欢迎回来，{player_name}。”）
- **目的**：把角色创建变成叙事动作；AI 从“系统”变成“认识你的人”。

### 拍 3：舱盖打开（1:30–2:00）

- **画面**：舱盖缓慢打开，光线涌入。镜头从第一人称拉远到第三人称：
  玩家坐在休眠舱里，周围是一排排蓝色舱灯，远处有应急灯和散落的线缆。
- **声音**：密封圈释放；压力平衡；远处警报；其他休眠舱的低鸣。
- **AI**：“备用系统只够支撑冬眠舱，和一小部分的我。”
- **玩家**：坐起，第一次看向房间。
- **目的**：展示“还有其他休眠者”；解释 AI 为什么只有一小部分在线。

### 拍 4：第一次站起来（2:00–2:45）

- **画面**：玩家站起，腿有些软；动力服支架在左侧，旁边是工具柜和应急包。
- **声音**：心跳；支架低鸣；脚踩金属地板。
- **AI**：“你先穿上动力服。我会一点一点帮你适应现在的环境。”
- **玩家**：走几步，靠近动力服。
- **目的**：先让玩家感到脆弱，再给动力服；移动教学不突兀。

### 拍 5：穿动力服 + 舰队说明（2:45–4:30）

- **画面**：动力服打开，玩家穿入。HUD 分层点亮：电池、温度、HUD、照明。
  视线变清晰，呼吸声被过滤，世界的声音变得更有层次。
- **声音**：伺服；密封；HUD 启动；AI 的声音比之前清晰一点。
- **AI**：“我们的飞船因为一场不明原因的意外，脱离了舰队的连接。”
- **AI**：（停顿）“它从 0.4c 的亚光速航行中脱离。可居星球相隔约 40 光年，一次航程要 100 年。”
- **AI**：“光速通信太慢，所以飞船必须亲自带着种子、移民、知识。”
- **AI**：“你已经睡了大部分航程。”
- **AI**：“单靠这艘船，我们无法再跨越下一个 40 光年。”
- **AI**：“所以我选择了 SEED-2338 星系的第三颗行星。这里播种已经完成，生存概率最高。”
- **AI**：“我们在这里降落修整，是为了避免最坏的情况。”
- **AI**：“最坏的情况，是在黑暗里漂到能源耗尽。”
- **AI**：“电池、温度、HUD 已上线。”
- **AI**：“电池只有 62%。别走太远。”
- **玩家**：穿服、看 HUD、测试照明。
- **可选互动**：问“什么意外？” → AI 停顿：“我不知道。或者……那段记录我现在读不到。”
- **目的**：第一次“拥有身体”；解释舰队失联、亚光速脱离、为什么不能直接离开、为什么选这颗星球；引入电池、温度、HUD。

### 拍 6：休眠舱区（4:30–5:15）

- **画面**：广角。一排排休眠舱，蓝色指示灯缓慢呼吸。
  其中一个舱是空的，玻璃有裂纹；舱位屏幕上的名字还在。
- **声音**：舱体低鸣；远处金属呻吟；AI 的声音在舱区里有一点回响。
- **AI**：“他们还活着。只要电不断，他们就会一直在。”
- **AI**：“别担心，我会看着他们。”
- **玩家**：自由查看休眠舱；可以停在空舱前。
- **07 号舱**：这一排里有一个空舱（07 号，安全官 Vale），完整互动见 [`anomaly-01-empty-pod.md`](anomaly-01-empty-pod.md)，对白树见 [`dialogue-pod-07.md`](dialogue-pod-07.md)。
- **目的**：建立“其他人还活着”的 stakes；埋下第一个异常。

### 拍 7：死掉的飞船（5:15–6:00）

- **画面**：通往船内的舱门；死掉的配电面板；工具柜；动力服前臂的便携打印机。
  墙上贴着褪色的警告标识；地上有散落的零件。
- **声音**：电力嗡鸣衰减；舱门卡住；风从船体缝隙里漏进来。
- **AI**：“主动力在迫降时彻底报废了。”
- **AI**：“我们需要一套新的基础电力。那是下一步。”
- **AI**：“先拿到工具和应急包。外面有能吃的东西。”
- **玩家**：打开工具柜，拿应急包，激活腕装打印机。
- **目的**：给出第二阶段目标（电力）；把打印作为“生存包”而不是菜单；把玩家推向食物阶段。

### 拍 8：第一个打印件（6:00–7:00）

- **画面**：舱门控制面板没有反应；玩家用手动释放打开舱门。
  腕装打印机投影出一把小刀/切割刃的线框；玩家选择、打印、拿起。
- **声音**：打印嗡鸣；刀刃卡入；手动释放的机械声。
- **AI**：“打印一把小刀。小的那种。”
- **AI**：“很好。带上它。我们需要能割东西的工具。”
- **玩家**：选择图纸、打印、拿刀、手动开门。
- **目的**：教便携打印机 0 级——只能打印小物品，需要原料和电；打印机是迫降生存包，不是工作台；给小刀为采集/陷阱做准备。

### 拍 9：第一次看见星球（7:00–8:00）

- **画面**：舱门打开。船体破口/观察窗露出外面的森林、天空、风。
  远处是海，或者被海包围的大陆轮廓。光线是真实的，不是 HUD。
- **声音**：风声；远处未知生物；动力服低鸣；AI 的声音安静下来。
- **AI**：“欢迎来到 SEED-2338，指挥官。”
- **AI**：“星球已经准备好了。现在，我们得先让你活下来。先找点吃的。”
- **玩家**：走向出口，获得完整控制。任务 `first_meal` 出现。
- **画面字卡**：`SEED-2338 // COLONY SITE`（地点字卡，不是最终标题）。
- **目的**：完成“花园已准备好，但人被困住”的揭示；把玩家推向降落点采集与陷阱。
- **后续**：AI 通过动力服视野继续给情境提示（兔子、草、陷阱、生火、食物安全）。
  出舱后**饥饿值**开始下降；AI 在 40% 和 15% 给阈值提示。

## 6. 可选互动与第一幕异常

### 可选互动

| 互动 | AI 反应 | 作用 |
|------|---------|------|
| 停在空休眠舱前 | “那个舱……记录损坏了。先修电，指挥官。” | 第一个异常：名单和舱位对不上 |
| 问“发生了什么？” | “有一段记录我现在读不到。等电力恢复，我再查。” | AI 的回避；为政变铺垫 |
| 问“什么意外？” | 停顿。“我不知道。或者……那段记录我现在读不到。” | 舰队失联的第一个异常 |
| 问“舰队呢？” | “失联了。等我恢复算力，再试着呼叫他们。” | 长线目标：重新联系人类 |
| 问“为什么是第三颗行星？” | “播种完成，有空气、水、生态。生存概率最高。” | 解释迫降选择 |
| 不穿动力服就走向舱门 | “等等。外面温度不够，你会冻伤的。” | 强化动力服必要性 |
| 查看其他休眠舱 | 显示姓名/专长（基因专家、医生等） | 为“叫醒谁”做铺垫 |
| 盯着船体破口 | “这不是普通的陨石撞击。” / 停顿 / “……先修电。” | 第二个异常：损坏方向不对 |

### 第一幕只放 2–3 个异常

建议开场只放：

1. **空休眠舱**：名单上有，舱里没有/被破坏。
2. **AI 的停顿**：被问及坠毁原因时，它说记录读不到。
3. **船体破损方向**（可选）：看起来像从里面发生的。

不要出现“政变”这个词；不要让 AI 长篇解释；玩家应该先觉得“不对劲”，再想“为什么”。

## 7. 镜头、UI、音频与操作

### 镜头

- 拍 0–2：第一人称，舱内近景；镜头运动很小。
- 拍 3：从第一人称拉远到第三人称，展示休眠舱区。
- 拍 4–6：第三人称，越肩；允许玩家自由看。
- 拍 7–9：第三人称，跟随；出口处用广角展示外部。
- 如果第一版只有第三人称，可用“舱内近景 + 拉远”替代第一人称，不做完整第一人称系统。

### UI

- 开场 UI 尽量少：字幕、交互提示、身份确认面板。
- 动力服穿上后，HUD 分层点亮：电池 → 温度 → 照明 → 交互提示。
- 身份确认面板是“医疗屏”，不是“创建角色”菜单。
- 字幕默认开启；可跳过；可调 AI 语音音量。
- 不显示完整任务列表，只显示当前目标：`穿上动力服` → `拿到工具` → `恢复基础电力`。

### 音频

- 开场以低频和环境声为主，不要一上来就放音乐。
- AI 声音：近场、略压缩、低算力时有轻微断续；恢复电力后逐渐稳定。
- 动力服：伺服、密封、HUD 启动、呼吸过滤。
- 飞船：金属应力、远处警报、电力嗡鸣衰减。
- 外部：风、远处生物、开阔空间；第一次打开舱门时留 2 秒无对白，只给环境声。

### 操作与节奏

- 0:20 给视角控制；1:30 给坐起；2:00 给行走；2:45 给动力服。
- 不要连续锁输入超过 20 秒；每段台词之间给玩家一点自由。
- 开场没有失败状态；不穿动力服只会被 AI 阻止/警告。
- 第一次死亡教学留到第一晚，不在开场。

### 对白系统的现状与取舍

`DialogueBox` 目前只对文本做 `tr()`，不支持 `{player_name}` 占位符。

第一版建议：

- 开场全部用“指挥官”和第二人称“你”，避免名字/代词依赖。
- 玩家名字显示在 HUD/档案里；等对白系统支持占位符后，再让 AI 叫名字。
- 如果一定要在开场叫名字，先在 game-utils 侧加通用替换能力，再同步回 Seed。

## 9. 可跳过与可访问性

- 首次播放完整开场；之后允许跳过（保留字幕和关键选择）。
- 字幕默认开启；AI 语音音量独立可调。
- 不做 QTE；不做强制镜头摇晃；晕动症选项关闭头部晃动。
- 身份确认不可跳过（需要名字/性别），但可以快速完成。
- 跳过开场时，自动设置 `opening_complete`、`power_suit_equipped`，并把玩家放在舱门内，任务直接进入 `first_meal`。

| 风险 | 表现 | 对策 |
