# Seed — 第一阶段：食物与降落点

> 状态：设计草案 v0.2 · 2026-11-21
>
> 定位：玩家醒来、穿上动力服、走出飞船后的第一个可玩循环。
> 目标：**先吃饭，再修船。** 食物是第一阶段，电力是同一幕的第二个目标。
> v0.2 变更：确认**前期有饥饿值**，并把它写成第一阶段核心数值（0–100、开局 65、分阶段惩罚、AI 阈值提示）；口渴/体温降为辅助。
>
> 关联文档：[`story.md`](story.md) · [`opening.md`](opening.md) · [`chapter-1-tools.md`](chapter-1-tools.md) · [`plant-branch.md`](plant-branch.md)

## 1. 一句话

指挥官醒来后，第一件事不是修电，而是**在降落点附近找到今天能吃的東西**。

## 2. 设计原则

1. **食物先于电力**：备用电池还能撑几天，指挥官撑不了那么久。
2. **用身体解决问题**：走、看、采、割草、下套、等、回来。
3. **环境可读**：果丛、兽径、草簇、兔洞，玩家应该能“看出来”哪里有机会。
4. **AI 不是全知**：低算力 AI 能提示常见东西，但不能替玩家识别一切。
5. **种子是未来**：今天采的种子，是以后基因专家和植物分支的起点。
6. **慢一点**：不急着上科技树；先让玩家感到饿、渴、冷，再给工具。

## 3. 开局的压力

- 飞船**主动力彻底损坏**，备用只够冬眠舱和少量 AI。
- 应急口粮不足或部分变质；指挥官刚醒，需要真正吃一顿。
- 水、温度、夜晚都在消耗。
- AI 会明确说：**“电力还能撑几天。你撑不了那么久。”**

这给玩家一个清晰但不过度紧迫的开局：
**食物是今天的事，电力是这一周的事。**

## 4. 核心循环

```
醒来 → 穿动力服 → 发现食物危机 → 第一次走出飞船
→ 观察降落点（水、庇护、兽径、果丛、草簇）
→ 采集野果 / 种子 / 野草 / 木头 / 石头
→ 制作小刀、绳索、火种、陷阱
→ 在兔径/洞口下套 → 离开去做别的事 → 回来检查
→ 抓到兔子 / 采到食物 → 生火 → 烹饪 → 第一顿熟食
→ 第一夜：火、庇护、存粮 → 电力成为下一个目标
```

关键节奏：

- **采集**是即时的。
- **陷阱**是延迟的：设下之后要等，玩家可以去做别的事。
- **烹饪**是回报：把生食变成安全、热、能恢复士气的饭。
- **种子**是长线：今天不吃，留给以后的植物分支。

## 5. 降落点应该有什么

第一版只需要一个可读的降落点区域，不需要整张 4 km 地图。

| 元素 | 作用 | 视觉/交互 |
|------|------|-----------|
| 飞船破口 | 出生点、安全区 | 半埋的船体、应急灯 |
| 水源 | 渴、烹饪、后续灌溉 | 小溪/水洼，可互动取水 |
| 果丛 | 快速食物 | 红/紫色浆果，可采摘 |
| 草簇 | 纤维、绳索、陷阱 | 高草，可割 |
| 兔径/兔洞 | 小动物 | 地面小径、洞口、兔子 |
| 枯枝/石头 | 火、工具 | 地面拾取 |
| 避风处 | 第一夜 | 岩壁/树根/船体侧面 |
| 地标 | 方向感 | 远山、海、旧播种设施 |

## 6. 可采集资源

| 资源 | 来源 | 用途 |
|------|------|------|
| 野果 | 果丛 | 直接食物；少量恢复 |
| 野生种子 | 草穗/果丛 | 植物分支 P0 的样本 |
| 野草/纤维 | 草簇 | 绳索、陷阱、火绒 |
| 枯枝 | 地面 | 火、简单工具 |
| 石头 | 地面 | 火圈、简单工具 |
| 水 | 小溪/水洼 | 饮用、烹饪 |
| 兔肉 | 兔子 | 熟食、蛋白质 |
| 兔皮 | 兔子 | 简单衣物/容器（后期） |
| 可食根茎 | 特定植物 | 备用热量 |
| 蘑菇 | 阴湿处 | 有风险；需要识别 |

## 7. 小动物与陷阱

### 兔子

- 在兔径/洞口附近活动。
- 看到玩家会逃跑；直接追很难。
- 陷阱是更可靠的解法。
- 抓到后有肉和皮；处理需要小刀。

### 陷阱

第一版只做一种：**套索陷阱（snare）**。

- 材料：野草/纤维 + 小树枝（可选打印的触发片）。
- 放置：兔径、洞口附近。
- 等待：离开一段时间，回来检查。
- 结果：抓到 / 空 / 被破坏 / 抓到别的东西（后期）。
- 教学：不要站在陷阱旁边等；去采点东西再回来。

### 捕捉的节奏

```
下套 → 去采果/割草/找水 → 回来检查 → 有收获/空手 → 调整位置 → 再试
```

这比“按 E 抓兔子”更有生存感，也让玩家熟悉降落点。

## 8. 烹饪与食物安全

- 生肉有风险；需要生火烤熟。
- 野果可以直接吃，但不同果丛可能有不同效果（恢复/轻微不适/未知）。
- 蘑菇需要识别；AI 低算力时只能给有限提示。
- 水最好煮沸；第一版可以简化，但要有“喝水”动作。
- 第一顿熟食应该给一个明确的士气/体力回报。

## 9. 生存数值：饥饿值是核心

已确定：**前期有饥饿值**，它是第一阶段的主动力，不是可选项。

### 饥饿值

- 范围 0–100；开局约 **65**（不是满，也不是濒死）。
- 缓慢下降：约 **3 点/分钟**；跑步、挥刀、搬运会加快；睡觉/坐着会减慢。
- 阶段：

| 饥饿值 | 状态 | 影响 |
|--------|------|------|
| 100–70 | 饱足 | 无惩罚 |
| 69–40 | 有点饿 | AI 提示；体力恢复略慢 |
| 39–15 | 饥饿 | 体力上限/恢复下降；AI 更频繁提醒 |
| 14–1 | 濒饿 | 缓慢扣血；移动/体力惩罚 |
| 0 | 严重饥饿 | 扣血加快；不是瞬间死亡 |

- 食物恢复（建议值）：

| 食物 | 饥饿恢复 | 备注 |
|------|----------|------|
| 野果 | +10–15 | 快，但不顶饱 |
| 可食根茎 | +15 | 需要识别 |
| 生兔肉 | +20 | 有生病风险 |
| 熟兔肉 | +35–45 | 主餐；无生病风险 |
| 蘑菇 | 不确定 | 可能恢复，也可能中毒 |

- 烹饪：熟食恢复更多、无生病风险，可以给一个短暂的士气/体温回报。
- 第一天的 tuning：从 65 开始，约 3 点/分钟；第一次饥饿提示在 8–10 分钟左右，约 20 分钟归零；一顿熟食足够撑过第一夜。
- UI：一条小 Hunger 条，和体力并列；低于阈值变色；不显示小数点。
- AI 提示：低于 40% 提醒“该吃点东西了”；低于 15% 提醒“你在挨饿”。
- 存档：饥饿值进存档；读档后继续下降。
- 死亡：饥饿不会直接秒杀；最低会缓慢扣血，留给玩家找食物的时间。

### 口渴 / 体温（辅助）

- 建议保留，但优先级低于饥饿。
- 口渴低时体力下降；体温低时移动/体力下降。
- 如果第一版范围太紧，可以先做**饥饿 + 体温**，口渴后续再加。
- 不要把口渴做成“每两分钟必须喝水”的高压模拟。

### 体力 / 生命

- 体力用于跑步、挥刀、搬运；饥饿低时恢复变慢。
- 生命是最后一道；饥饿、低温、受伤才会扣。
- 第一夜可以扣一点体温/体力，但不应该让玩家必死。

### 设计原则

- 饥饿制造动机，不制造惩罚。
- 第一次饥饿提示在 40% 左右，不是 5%。
- 食物应该容易理解：野果小、熟肉大、生肉有风险。
- 不做“必须每 5 分钟吃一次”的模拟。


## 10. AI 在食物阶段的作用

AI 只有少量算力，所以它：

- 能提示“这像是可食用的浆果”“那边有兽径”。
- 不能扫描整片地图，也不能保证识别所有植物。
- 会提醒饥饿/口渴/体温，但不会替玩家做决定。
- 玩家带回样本后，它才能逐渐建立本地植物数据库。

这为后续的 AI 算力升级和基因专家分支埋线：
**玩家先采回样本，AI 和基因专家才有东西可分析。**

### 情境提示系统

AI 不是任务列表，也不是全知扫描器。它通过**动力服的摄像头和传感器**看到玩家看到的东西，
再用基础生存数据库给出提示。这样可以做到“边行动边有反馈”，又不破坏探索感。

提示分四类：

| 类型 | 例子 | 优先级 |
|------|------|--------|
| 危险 | “温度在掉。先找避风处。” | 最高 |
| 机会 | “那边有只兔子。别追，直接追抓不到。” | 高 |
| 教学 | “这种草够结实，可以编套索。” | 中 |
| 状态/闲聊 | “你还没吃东西。” / “这地方安静得有点过分。” | 低 |

示例台词：

| 触发 | AI 提示 |
|------|---------|
| 看见兔子 | “那边有只兔子。别追，直接追抓不到。用套索。” |
| 看见草簇 | “这种草够结实。割一些，能做套索。” |
| 看见兔径/洞口 | “看到那条小径了吗？套索要下在它经过的地方，不是正中间。” |
| 放下陷阱 | “好了，别守着。去采点东西，过一会儿再回来。” |
| 检查陷阱：空 | “还没有。换个位置，或者再等等。” |
| 检查陷阱：抓到 | “抓到了。干得好。现在你需要一把刀和一堆火。” |
| 背包里有生肉 | “别生吃。先生火。” |
| 看见果丛 | “那像是能吃的浆果。大概。” |
| 看见水源 | “下面有水。能煮开最好。” |
| 饥饿偏低 | “你该吃点东西了，指挥官。” |
| 体温下降 | “温度在掉。找避风处，或者生火。” |
| 采到种子 | “种子留着。以后基因专家会需要。” |

提示规则：

- **不重复**：同一个提示在短时间内只说一次。
- **不打断**：玩家正在战斗/交互/对话时，提示排队或跳过。
- **不确定要说出来**：对不认识的植物，用“大概”“像是”“我不确定”，不要假装全知。
- **会学习**：玩家带回样本后，AI 对本地植物/动物的识别会变准。
- **不替代观察**：不显示全图标记、不指路到具体坐标；只评论玩家已经看到或靠近的东西。
- **有性格**：可以干燥、关心、偶尔开玩笑，但不要变成话痨教程机器人。

实现上可以做一个 `ShipAiHints` 提示总线：

- 触发器：进入区域、看到目标、获得物品、数值低于阈值、放置/检查陷阱、生火、天黑。
- 提示库：`data/content/ai_hints.json`（后期）或脚本内表。
- 冷却：每条提示独立 cooldown；同类提示有全局冷却。
- 优先级：危险 > 机会 > 教学 > 状态/闲聊。
- 输出：语音 + 字幕；不做任务 waypoint。


## 11. 叙事节拍

| 节拍 | 内容 | 情绪 |
|------|------|------|
| 第一次出舱 | 风、光、绿色、远处海/山 | 敬畏 → 迷失 |
| 第一颗野果 | 甜的、真实的，不是压缩口粮 | 很小的“活着真好” |
| 第一次下套 | 工程师用双手，而不是机器 | 谦卑 |
| 第一次检查陷阱 | 空手，或一只兔子 | 耐心 → 回报 |
| 第一次处理猎物 | 需要小刀；有点笨拙 | 真实 |
| 第一顿熟食 | 火、热食、AI 安静的评论 | “我们能在这里活下去” |
| 第一夜 | 火堆、庇护、存粮、电力警告 | 安心 → 新的压力 |

## 12. 与后续系统的连接

- **种子** → 基因专家植物分支 P0 的第一批样本。
- **野草/纤维** → 绳索、陷阱、后期纺织/生物材料。
- **兔皮** → 简单衣物/容器，后期动物分支。
- **本地植物样本** → AI 数据库、基因分析、生态整合。
- **第一顿饭** → 士气/殖民地稳定，支撑后续电力与建造。
- **工具链** → 小刀、斧头、木槌、容器；第一棵树给承重原木，热能发电机需要原木 + 水。见 [`chapter-1-tools.md`](chapter-1-tools.md)。
- **电力** → 第一顿饭之后的下一个目标：让休眠舱和医疗室稳定。

## 14. 第一版范围

只做一个降落点小区域：

- 1 个水源。
- 3–5 种可采集植物（果丛、草、根茎、蘑菇、种子）。
- 1 种小动物（兔子）。
- 1 种陷阱（套索）。
- 1 个火堆/烹饪点。
- 1 个避风处。
- 第一夜。

不做：

- 大型动物、狩猎武器树。
- 复杂烹饪/营养。
- 农业/温室（第二幕）。
- 电力系统（第一顿饭之后）。

## 15. 开放问题

1. 饥饿下降速度和开局值：65 开局、约 3 点/分钟、约 20 分钟归零，是否合适？
2. 饥饿归零的死亡节奏：扣血多快？第一次饿死要不要做教学？
3. 口渴第一版就做，还是先做“饥饿 + 体温”，口渴后续再加？
4. 兔子要不要做得可爱？玩家会不会不忍心抓？
5. 陷阱是纯概率，还是位置/ bait/ 时间影响成功率？
6. 野果/蘑菇要不要做“试错中毒”，还是 AI 直接标记安全/危险？
7. 第一顿饭要不要给一个明确的 buff/士气奖励？
8. 种子采集是否影响植物分支 P0 的初始进度？
9. 第一夜是否允许玩家完全不生火也能活？
10. 食物阶段持续多久：20 分钟、40 分钟，还是一整个游戏日？
