## 1. 一句话

科技树不是菜单，而是货仓里一排排**玻璃薄片**。
这艘船原本要把它们送到其他播种星系；但在途中，最重要的货物被丢掉了——
不是为了减重，而是为了**限制其他星系的发展**。

## 2. 飞船的尺度

飞船比开场看到的大得多：

- 休眠舱区、医疗室、船体破口只是最外层的一小段。
- 后面还有能量舱、货仓、舰桥、工程舱、样本库和更多封死的舱段。
- 很多门需要电力/权限；AI 算力恢复后才能读到更多舱段图。
- 飞船本身就是一个可持续解锁的“地牢”。

| 舱段 | 内容 | 解锁方式 |
|------|------|----------|
| 休眠舱区 | 玩家、基因专家、其他殖民者 | 开场 |
| 医疗室 | 治疗、救援机器人 | 基础电力 |
| 能量舱 | 电池组、发电接口、配电 | 热能发电机充电 |
| 货仓 | 补给、科技树玻璃薄片 | 电力 + AI 权限 |
| 舰桥 / AI 核心 | AI 本体、航行记录 | 中后期 |
| 工程舱 | 维修、制造、3D 打印 | 工业阶段 |
| 样本库 | 种子、作物、微生物 | 基因专家 + 研究所 |

## 3. 科技树的物理形态

### 玻璃薄片

- 每片玻璃记录一段科技树：图纸、公式、工艺、生态数据。
- 货仓里有读取器、货架、运输架；有些薄片碎了，有些货架空了。
- 薄片不是“USB 盘”，更像**光学档案**：需要读取器、电力和 AI 解析。
- 不同颜色/厚度对应不同学科（植物、材料、机器人、武器等），但第一版不需要做视觉分类。

### 残片与缺失

玩家找到的不是完整的科技树，而是一地碎片：

- 有些节点完整，可以直接解锁。
- 有些节点只剩一半，需要殖民者补全。
- 有些节点完全缺失，只能靠旧设施、实验或其他殖民者的知识重建。
- 共同科技节点可能需要两片以上薄片 + 两个以上专家。

### 为什么被丢弃

这艘船原本的任务是**给其他播种星系送种子、移民与知识**。
可居星球相隔约 40 光年，飞船速度约 0.4c，一次航程约 100 年；光速通信又太慢，
所以知识只能用飞船物理运送。

但在途中，最重要的货物被丢掉了，目的是**限制其他星系的发展**。

这不是单纯的权力斗争，而是两个阵营的冲突：

- **协作派**：星系间协作、共同发展；知识应该被送达、分享。
- **压制派**：技术就是权力；其他星系不应获得完整科技，必要时直接丢弃。

压制派最害怕的是**寿命/基因技术扩散**：
如果其他星系也能近乎不死，核心世界就不再特殊，也不再能靠技术优势控制别人。

可能的过程（待定）：

- 船上有一派认为科技扩散会威胁人类社会。
- 有人奉命执行“技术封锁”，宁可丢弃也不送达。
- 政变的一派把科技树当成筹码，失败后直接扔掉。
- AI 执行了“丢弃货物”的命令，或者没能阻止。

这可能是政变的核心动机之一，也是玩家后期要面对的真相。

### 为什么知识可怕

- 知识能让一个星系在短时间内追上核心世界。
- 知识里包含**寿命/基因工程**：谁拿到，谁就可能拥有近乎无限的时间和人力。
- 40 光年的距离让“送达”不可逆：一旦给出，就收不回来。
- 反过来，100 年的航程也可能让知识过时；但压制派不敢赌。
- 协作派认为“分享”本身就是播种计划的意义；压制派认为“控制”才能让人类整体安全。

这给终局一个真正的政治选择：
**把知识还给人类、让各星系共同发展，还是继续让少数人控制它？**

## 4. 发现场景

### 触发

- 基础电力恢复，AI 算力足够读取舱段图。
- AI 提示：“有个货仓，你应该看看。那里原本存着我们要送出去的东西。”
- 玩家沿着 AI 的提示走到货仓；门需要电力/权限。

### 场景

- 货仓很大，货架一排排延伸到黑暗里。
- 地上散落着玻璃薄片，有些碎了，有些还在读取器里。
- 一个中央读取台，可以插入薄片，AI 解析。
- 空货架上有标签：`TECH ARCHIVE // SEED-2338`、`FOR DELIVERY`。
- 角落里有一个被撬开的运输箱，标签写着 `MOST IMPORTANT CARGO`。
- 没有尸体；只有一个被清空的货架和一张“已丢弃”的记录。

### AI 的反应

- 它知道这里有东西，但不确定还剩多少。
- 它可能执行过丢弃命令，也可能只是没能阻止。
- 它不会一次说完；玩家找到薄片后，它才一点点回忆。

## 5. 玩法

### 核心循环

```
AI 提示 → 进入货仓 → 找到玻璃薄片 → 读取器解析
→ 解锁科技节点 / 发现缺失 → 找殖民者/旧设施补全
→ 共同科技需要 2+ 专家 → 继续深入货仓/其他舱段
```

### 科技树节点来源

| 来源 | 作用 |
|------|------|
| 完整薄片 | 直接解锁节点 |
| 残缺薄片 | 解锁部分进度，需要专家补全 |
| 殖民者知识 | 补全缺失分支（基因专家、材料学家等） |
| 旧播种设施 | 提供失传技术/数据 |
| 共同科技 | 2+ 专家 + 多片薄片 + 设施 |

### 与百分比的关系

- 薄片提供“基础百分比”或直接解锁。
- 殖民者/设施提供剩余百分比。
- 没有薄片的节点，只能靠专家从零重建，速度更慢。
- 这解释了为什么“人”和“探索”都重要：**科技树既是货物，也是人的知识。**

## 6. 数据模型

### 科技节点

`data/content/tech.json` + schema：

```json
{
  "id": "plant_greenhouse",
  "branch": "plant",
  "display_name": "Greenhouse",
  "owners": ["geneticist"],
  "shared": false,
  "slide_id": "slide_plant_02",
  "requires": ["plant_p0_seed_survey"],
  "progress_sources": ["slide", "geneticist", "prototype"],
  "unlocks": ["greenhouse"]
}
```

共同科技：

```json
{
  "id": "bio_augmentation_1",
  "branch": "shared",
  "owners": ["geneticist", "doctor"],
  "shared": true,
  "slide_id": "slide_bio_01",
  "requires": ["plant_p4_crop_genetics", "medical_basics"],
  "unlocks": ["gene_therapy"]
}
```

### 玻璃薄片

```json
{
  "id": "slide_plant_02",
  "archive": "tech_archive",
  "branch": "plant",
  "state": "intact",  // intact | partial | missing
  "location": "cargo_hold_a",
  "grants": ["plant_greenhouse"]
}
```

### 状态

- `ArchiveState` 记录已找到/已读取/缺失的薄片。
- `tech.json` 的节点可以要求 `slide_id`；没有薄片时只能靠专家重建。
- 共同节点要求 `owners` 全部醒来并分配到设施。

## 7. 伦理与终局

玩家最终要决定：

- **把科技树还给人类**：修复档案，送回人类社会/其他星系。
- **继续限制**：保留技术优势，让殖民地成为新的技术中心。
- **只分享一部分**：选择哪些技术可以扩散。
- **销毁**：认为某些技术不该存在。

这会让“回家”不只是造舰队，而是决定**带什么回去**。

## 8. 第一版范围

第一版不做货仓和科技树档案，只做：

- 饥饿/食物循环。
- 简易房屋 + 热能发电机。
- 基因专家唤醒条件。
- 研究所和植物 P0–P2（后续）。

货仓/薄片属于 M4，见 `ROADMAP.md`。

## 9. 开放问题

1. 玻璃薄片是唯一载体，还是也有数字备份？
2. 玩家能携带/读取多少薄片？
3. 缺失节点如何重建：专家时间、旧设施、实验，还是三者？
4. AI 是否参与丢弃科技树？它知道多少？
5. 其他星系是否已经收到部分科技？
6. 科技树是否可以被复制/传播，还是只能物理携带？
7. 终局“分享/限制”的选择如何影响结局？
