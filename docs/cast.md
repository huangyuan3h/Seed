# Seed — Cast

> 状态：角色设定草案 v0.4 · 2026-11-21
>
> 原则：小阵容、每人一根支柱、名字好念、每个人都有表里两面。
> **你唤醒的每一个核心队员都是可靠的小队成员**——他们可以有专业冲突、性格摩擦、旧怨，
> 但不会在背后捅刀。悬疑留在过去、AI 和真相处理，而不是“谁是内鬼”。
> 玩家只控制指挥官；其他人是 NPC 专家，不是可操作角色。

### 寿命与年龄

- 基因工程让衰老几乎被解决：外观年龄可以长期维持在 30–50 岁，实际年龄可以几百岁。
- 休眠不增加生物年龄；100 年航程对船员来说更像“睡了很久”，不是“过完一生”。
- 核心世界有 500+ 岁的老人；这艘船的船员算“中青年”，但也都经历过多份职业/人生。
- 死亡更多来自事故、暴力、资源失败，而不是衰老；医疗室和救援机器人因此更重要。
- 自愿参加 100 年单程航行，是只有近乎不死的人才会做的决定。
- 对白里通常说“看起来多大”，不主动报实际年龄；实际年龄是人物关系的暗线。

### 政治立场（协作派 vs 压制派）

政变是两种理念的冲突：

- **协作派**：星系间协作、共同发展；科技应该被分享。
- **压制派**：技术就是权力；其他星系不应获得完整科技；科技树必须被控制/丢弃。

| 角色 | 立场 | 说明 |
|------|------|------|
| 玩家 / 指挥官 | **协作派** | 相信星系间协作、共同发展；AI 因此选择唤醒 |
| Mira | 协作派，但可能执行过压制派命令 | 愧疚/记忆缺口；叫醒主角是补救或赎罪 |
| Sana | 协作派 | 科学应该被分享；种子不该被垄断 |
| Tomas | 协作派（草根） | 反中央控制；相信邻里互助 |
| Lin | 协作派，但对技术扩散有保留 | 技术要负责，不是无条件开放 |
| Juno | 协作派 / 开放技术 | 讨厌把知识锁进保险柜 |
| Vale | 协作派 | 试图阻止丢弃科技树；因此失踪 |
| Yusuf | 协作派 / 人道主义 | 先救人，再谈阵营 |

**压制派不在可唤醒小队里。** 他们可能在政变中死亡、离开、被冻结在别的舱段，或者根本不在船上。
核心队员可以有专业/性格冲突，但不会背叛；悬疑是“过去发生了什么”，不是“谁是内鬼”。

## 2. 详细设定

### Mira / 米拉 — 船载 AI

- **性别/呈现**：女性化声音与名字；技术上无性别。英文用 she/her，中文用“她”或“米拉”。
- **年龄**：在线约 180 年；在船上约 100 年；只有约 47 年连续记忆。
- **声音**：偏低、克制、温暖；低算力时有轻微断续和延迟。
- **性格**：干燥幽默、保护欲强、带一点官僚气；对船员有感情，但不太会承认。
- **爱好**：
  - 整理地球音乐播放列表。
  - 运行虚拟植物园/生态模拟。
  - 看星星，记录轨道和天气。
  - 收集船员的故事，偶尔讲冷笑话。
- **表里**：
  - 表面：可靠、礼貌、有点疲惫的船载智能。
  - 里层：对“科技树被丢弃”知道得比它承认的多；记忆有缺口；可能执行过命令，也可能只是没能阻止。
- **对玩家**：称“指挥官”；确认名字后偶尔叫名字。她叫醒玩家，等于亲手关掉了伊甸。
- **口头禅**：“指挥官，我建议……” / “……那段记录我现在读不到。”

### Dr. Sana Ahn / 萨娜·安 — 基因专家

- **性别**：女（she/her）。
- **年龄**：外观 34 / 实际 219；在种子库工作了几十年。
- **声音**：轻、准确；说到植物时会明显亮起来。
- **性格**：好奇、细致、安静地固执；不擅长政治，但对自己相信的事很硬。
- **爱好**：做饭、植物速写、整理种子目录、收集旧地球食谱。
- **表里**：
  - 表面：温和的植物/基因专家，第二个醒来的人。
  - 里层：她的导师参与设计过种子库；她知道有些种子“不应该缺失”。
- **关系**：和 Lin 在“自然 vs 工程”上经常争论；和 Yusuf 在生物伦理上聊得来。
- **目标**：让殖民地吃上一顿像家的饭，而不只是热量。
- **口头禅**：“先让它活下来，再让它长得好。”

### Tomas Rook / 托马斯·鲁克 — 建造工程师

- **性别**：男（he/him）。
- **年龄**：外观 42 / 实际 286；在多个殖民地盖过房子。
- **声音**：低沉、慢、干。
- **性格**：直、可靠、有点顽固；不相信全自动，觉得“机器不知道什么时候该停”。
- **爱好**：木工、纸牌、老西部片、修理旧工具。
- **表里**：
  - 表面：大个子建造工程师，先把屋顶搭起来的人。
  - 里层：以前是工会组织者，对“指挥链”有天然警惕；不是政变参与者，但不喜欢被命令。
- **关系**：和 Juno 在“自动建造 vs 手工建造”上互相看不顺眼，但配合很好。
- **目标**：让殖民地有一个真正能住人的房子。
- **口头禅**：“能住人，再谈好看。”

### Dr. Lin Qiao / 林乔 — 材料学家

- **性别**：女（she/her）。
- **年龄**：外观 39 / 实际 174；研究材料一个多世纪。
- **声音**：快、准、短；不耐烦时更短。
- **性格**：完美主义、直接、有点冷；对材料有近乎审美的执着。
- **爱好**：茶、金属断口照片、书法、收集老式工具。
- **表里**：
  - 表面：材料学家，负责合金、复材、3D 打印原料、装甲、船体。
  - 里层：她的导师参与制造过科技树玻璃薄片的封装；她一眼能认出那些碎片。
- **关系**：和 Sana 争论“改造自然”的边界；和 Juno 一起做自动化产线。
- **目标**：造出能跨星系的材料，而不是只会补锅。
- **口头禅**：“材料不会说谎。人会。”

### Juno Park / 朱诺·帕克 — 机器人工程师

- **性别**：非二元（they/them）；中文用“朱诺”/“TA”，对白尽量用名字和第二人称。
- **年龄**：外观 28 / 实际 121；船上最年轻的人类之一。
- **声音**：快、轻、带技术俚语；兴奋时会连珠炮。
- **性格**：好奇、爱玩、 improviser；对风险钝感，对机器比对人更有耐心。
- **爱好**：无人机竞速、复古游戏、音乐合成、拆解一切会动的东西。
- **表里**：
  - 表面：机器人工程师，负责无人机、自动化、建造/物流机器人、AI 硬件。
  - 里层：船上搬运科技树货箱的机器人，有一部分是 TA 调的；日志可能记录了“谁下令丢弃”。
- **关系**：和 Tomas 在自动化上斗嘴；和 Mira 关系像“同事”，会互相吐槽。
- **目标**：让殖民地自己运转，这样人可以去探索。
- **口头禅**：“让机器去干，我们去看点有意思的。”

### Vale / 瓦尔 — 武器专家（失踪）

- **性别**：女（she/her）。
- **年龄**：外观 36 / 实际 158；做过多年安全官。
- **声音**：低、安静、克制；很少提高音量。
- **性格**：警觉、忠诚、寡言；对陌生人先观察再开口。
- **爱好**：木雕、射击、旧侦探小说。
- **表里**：
  - 表面：07 号舱的安全官，本该是武器/防御/狩猎/边界分支的拥有者。
  - 里层：她试图阻止科技树被丢弃；07 号舱是空的，没有尸体；她可能还活着。
- **关系**：和 Mira 有旧交；Mira 对她的失踪有愧疚或隐瞒。
- **剧情作用**：武器分支暂时锁死；玩家找到她，才能解锁防御/军械/边界科技。
- **口头禅**：“先看清楚，再拔枪。”

### Dr. Yusuf Erdem / 优素福·埃尔德姆 — 医生（可选）

- **性别**：男（he/him）。
- **年龄**：外观 55 / 实际 341；行医两百多年。
- **声音**：温暖、不急、略带沙哑。
- **性格**：耐心、冷静、黑色幽默；见过太多，所以不轻易评判。
- **爱好**：国际象棋、做饭、读诗。
- **表里**：
  - 表面：医生，负责医疗、辐射、改造恢复、士气。
  - 里层：政变那晚他处理过伤员；医疗日志可能记录了谁受伤、谁在场。
- **关系**：和 Sana 在生物伦理/人体改造上合作；和 Tomas 下棋。
- **目标**：让殖民地不只是一个能活下来的地方，也是一个值得活的地方。
- **口头禅**：“先止血，再讲道理。”

## 3. 关系网

```
Mira ── 旧交/隐瞒 ── Vale（失踪）
Mira ── 照顾/吐槽 ── Juno
Sana ── 自然 vs 工程 ── Lin
Tomas ── 手工 vs 自动 ── Juno
Sana ── 生物伦理 ── Yusuf
Lin ── 材料/产线 ── Juno
Tomas ── 棋友 ── Yusuf
```

- **Mira + Vale**：07 号舱的核心。Mira 可能知道 Vale 为什么失踪，也可能执行过相反的命令。
- **Sana + Lin**：一个想让生命适应，一个想让材料适应；两人都尊重对方的专业。
- **Tomas + Juno**：建造与自动化的代际/方法冲突；关键时刻互相救命。
- **Sana + Yusuf**：人体改造/基因治疗的伦理搭档。
- **Lin + Juno**：自动化铸造/3D 打印产线的共同科技。
- **Tomas + Yusuf**：下棋、聊天，给殖民地一点日常。

## 4. 过去线索矩阵

这里的“隐瞒”不是叛变，而是**不愿谈、羞于谈、或受保密约束**。每个人都是可靠的小队成员。

| 角色 | 知道什么 | 隐瞒/不愿谈什么 |
|------|----------|-----------------|
| Mira | 科技树被丢弃的命令/执行过程 | 记忆缺口；可能执行过，也可能没能阻止；对此有愧疚 |
| Vale | 谁下令丢弃、为什么 | 失踪；07 号舱空舱；她试图阻止，不是参与者 |
| Juno | 搬运货箱的机器人日志 | 机器人是 TA 调的；可能怕被责怪，不是共犯 |
| Lin | 玻璃薄片的封装来源 | 导师参与过；她认得出碎片，但不愿相信导师有份 |
| Yusuf | 政变当晚的伤员记录 | 医疗保密；不愿用伤员的痛苦去指认谁 |
| Sana | 种子库缺失的种子 | 导师参与设计；她怕承认“缺的不是随机” |
| Tomas | 基本不知情 | 工会背景让他不信任指挥链，但不是参与者 |

建议节奏：第一幕只让玩家认识人；第二幕开始拼线索；第三幕面对真相和选择——
不是“找出内鬼”，而是“知道了以后怎么办”。

## 6. 开放问题

1. Vale 是死是活？玩家在哪里找到她？
2. Mira 是政变的执行者、受害者，还是旁观者？
3. Juno 知道机器人运的是什么吗？
4. Lin 的导师是政变人物，还是被利用？
5. Yusuf 的医疗日志是线索还是红鲱鱼？
6. 医生是第 6 人，还是把医疗并给 Sana/Yusuf 二选一？
7. 年龄/名字是否最终确定？是否需要更多文化多样性？
8. 玩家和谁可以有更深的个人关系？还是保持“指挥官与专家”的距离？
