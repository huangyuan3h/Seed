# Seed — 热能发电

> 状态：设计草案 v0.1 · 2026-11-21
>
> 定位：前期的**启动电源**。烧木材/生物质，给飞船能量舱充电，够唤醒第一个同伴。
> 不是最终电网；太阳能/风能、地热、核能都是后续。
>
> 关联文档：[`story.md`](story.md) · [`colonist-wake-chain.md`](colonist-wake-chain.md) · [`ROADMAP.md`](ROADMAP.md)

## 1. 一句话

热能发电机不是“一个发电按钮”，而是一套**火 → 水 → 蒸汽 → 旋转 → 电**的小型动力系统。
玩家先把它搭起来，才能把飞船从“濒死电池”变成“能再叫醒一个人”。

## 2. 技术路线选择

| 方案 | 优点 | 缺点 | 建议 |
|------|------|------|------|
| **生物质蒸汽机**（推荐） | 直观、可视化强、能长出压力/冷凝/自动加料 | 组件多、需要水 | 第一版主线 |
| 热电模块（TEG） | 无运动部件、安静、紧凑 | 需要稀有材料，前期不现实 | 后期升级 |
| 斯特林发动机 | 外部燃烧、安静 | 玩家不熟悉、视觉不明显 | 可选变体 |
| 直接燃烧发电 | 最简单 | 效率低、缺少工程感 | 不做 |

推荐第一版：**生物质蒸汽机**。
它和“工程师主角 + 飞船残骸 + 3D 打印 + 殖民地”最契合，也能自然解释压力、阀门、冷凝、维护这些玩法。

## 3. 第一版组件

### 3.1 核心组件

| 组件 | 作用 | 来源 |
|------|------|------|
| **燃烧室 / Furnace** | 烧木材/生物质，产生热 | 石头/黏土 + 金属格栅 |
| **锅炉 / Boiler** | 水 → 蒸汽；承压容器 | 金属板 + 管道 + 密封件 |
| **蒸汽活塞 / Steam Piston** | 蒸汽推动活塞/飞轮，产生旋转 |  salvage 泵体 + 3D 打印活塞环 |
| **发电机 / Alternator** | 旋转 → 电 | 从飞船残骸拆出/打印线圈 |
| **管道与阀门 / Pipes & Valves** | 蒸汽/水循环；泄压阀保证安全 | 金属管 + 密封件 |
| **输电线 / Power Cable** | 接到飞船能量舱 | 铜线/ salvage |
| **基座 / Frame** | 固定、减震、承重 | 木材/废金属 |
| **燃料口 / Fuel Feed** | 手动加木材/生物质 | 漏斗/舱门 |
| **加水口 / Water Fill** | 手动加水 | 水箱/阀门 |
| **调速器 / Governor**（T2） | 稳定转速，防止过载 | 机械配重/AI 控制 |

### 3.2 第一版建造材料（建议）

| 资源 | 数量 | 用途 |
|------|------|------|
| 木材 / 生物质 | 8 | 基座 + 初始燃料 |
| 石头 / 黏土 | 6 | 燃烧室内衬 |
| 废金属 / scrap | 6 | 锅炉、管道、框架 |
| 纤维 | 4 | 密封垫、保温 |
| 电子件 | 2 | 发电机/接线（从飞船残骸拆） |
| 水 | 5 | 首次注水 |

> 当前灰盒只用 `wood 8 + fiber 4`；真正的建造会加入 stone / scrap / electronics / water。
> 这些资源在后续内容表里补，不在第一版强求。

### 3.3 第一版不做的组件

- 冷凝器/闭式水循环（T2）
- 自动加料/除灰（T3）
- 热电模块/余热回收（T4）
- 地热换热器（独立分支）
- 核反应堆（后期）

## 4. 科技解锁

### 4.1 科技节点

| 节点 | 名称 | 前置 | 解锁 |
|------|------|------|------|
| `power_basics` | 基础电力 | 开场 / AI 蓝图 | 看懂飞船电网、接线、安全 |
| `thermal_steam_1` | 热能发电机 I | `power_basics` + 检查飞船动力舱 | 燃烧室、锅炉、活塞、发电机、输电线 |
| `thermal_steam_2` | 热能发电机 II | `thermal_steam_1` + 材料学/建造 | 冷凝器、闭式水循环、泄压阀、调速器、保温 |
| `thermal_steam_3` | 热能发电机 III | `thermal_steam_2` + 机器人工程师 | 自动加料、除灰、AI 监控、负载调节 |
| `thermal_teg` | 热电模块 | `thermal_steam_2` + 材料学家 | 无运动部件、静音、余热发电 |
| `geothermal_tap` | 地热接入 | 材料 + 建造 + 钻探 | 可持续基荷电力 |

### 4.2 第一台发电机怎么解锁

不要求玩家先点一堆科技。推荐：

1. 玩家检查飞船动力舱/能量舱（`assess_damage`）。
2. AI 读取残存的工程数据库，给出 `thermal_steam_1` 的**现场应急蓝图**。
3. 玩家收集木材/石头/废金属/纤维/电子件，搭第一台。
4. 接上飞船能量舱，开始充电。

这样第一台发电机是**剧情/探索解锁**，不是科技树 grind。
后续 II/III/热电/地热才需要殖民者和共同科技。

### 4.3 谁拥有这条科技线

- **玩家（指挥官/工程师）**：能独立完成 Tier 1；这是主角的专业。
- **建造工程师**：Tier 2 结构/锅炉/大型机组。
- **材料学家**：耐热合金、保温、热电模块。
- **机器人工程师**：自动加料、除灰、监控。
- **AI**：效率分析、负载管理、故障预警。
- **共同科技**：
  - 建造 + 材料 → 高压锅炉
  - 材料 + 机器人 → 热电模块/余热回收
  - 建造 + 机器人 → 自动燃料处理

## 5. 玩法循环

```
检查动力舱 → 拿到应急蓝图
→ 收集木材/石头/废金属/纤维/电子件
→ 建燃烧室 + 锅炉 + 活塞 + 发电机
→ 接水、加燃料、点火
→ 接上飞船能量舱
→ 充电到 20 电力
→ 唤醒基因专家
→ 后续升级冷凝器/自动加料/热电/地热
```

### 日常维护

- 加燃料（木材/生物质）。
- 加水/检查水位。
- 清灰（T3 前手动）。
- 检查压力/温度。
- 负载高时 AI 提醒降载或加机组。

## 6. 模拟模型（第一版）

不要做完整流体仿真。第一版用抽象状态：

| 状态 | 行为 |
|------|------|
| `fuel` | 燃烧消耗；耗尽则停机 |
| `water` | 蒸发/泄漏消耗；耗尽则过热/停机 |
| `heat` | 点火后上升；影响效率/压力 |
| `pressure` | 过高触发泄压阀；T1 可能只报警 |
| `rpm` | 活塞/飞轮转速；影响输出 |
| `power_output` | 与 heat/rpm/负载相关 |
| `battery_charge` | 充进飞船能量舱 |

第一版可以简化成：

```
fuel + water + running → power_output → charge battery
```

压力/温度只做提示和停机条件，不做真实热力学。

## 7. 故障与压力

| 故障 | 触发 | 结果 |
|------|------|------|
| 燃料耗尽 | 没加木材/生物质 | 输出下降 → 停机，AI 提醒 |
| 水位过低 | 没加水/泄漏 | 过热、损坏锅炉 |
| 压力过高 | 负载突降/阀门坏 | 泄压/报警；T2 前可能损坏 |
| 转速不稳 | 负载波动/调速器缺失 | 输出波动，灯光闪烁 |
| 积灰 | 长时间运行 | 效率下降，需要清理 |
| 结冰 | 低温环境 | 水管/锅炉损坏，需要保温 |

第一版只做“燃料耗尽/水位低/停机”三种，避免过度复杂。

## 8. 副产物与循环

- **灰烬** → 堆肥/土壤改良（植物分支 P3）。
- **余热** → 温室加热/殖民地供暖（T2/T4）。
- **蒸汽冷凝水** → 回收（T2 闭式循环）。
- **生物质燃料** → 基因专家的快速生长作物/木材（后期）。
- **废金属/电子件** → 飞船残骸、旧设施、材料学家。

这让热能发电机不只是“电”，而是殖民地生态的一部分。

## 10. 开放问题
