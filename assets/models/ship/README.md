# Ship model kit

Generated by `tools/blender/build_ship_models.py` for Blender 5.2+.
Do not hand-edit the `.glb` files; edit the generator and re-run:

```bash
blender -b --python tools/blender/build_ship_models.py -- all
python3 tools/godot/generate_ship_scenes.py
```

## Layout

```
kit/        reusable 4 m wall/floor/ceiling, 8 m corridor, 12 m junction, airlock
props/      cryo pod, broken Pod 07, suit rack, autodoc, consoles, doors, crates
sections/   64x30 m cryo bay shell, 16x12 m med bay shell
exterior/   ~1.28 km crashed hull, breach ramp
```

All models are metric (1 unit = 1 m), +Z forward after import, low-poly,
flat-shaded, with simple Principled materials. Room shells include a
`*-colonly` mesh that Godot imports as a `StaticBody3D` collision shape.
