# Seed generated model kit

First-pass authored replacements for the procedural placeholders in
`scripts/world/world_art.gd` and the greybox build sites.

Generated by [`tools/blender/build_seed_assets.py`](../../../tools/blender/build_seed_assets.py)
with Blender 5.2. Re-run that script to reproduce or tune; do not hand-edit the
`.glb` files.

## Import contract

- glTF 2.0 binary (`.glb`), +Y up, model front +Z.
- 1 unit = 1 metre, origin at ground contact.
- Palette materials only; no image textures, no rig, no animations.
- Flat shading; safe to add a Godot `MeshInstance3D` per file.

`prop_pod_07.glb`, `prop_shelter.glb` and `prop_thermal_generator.glb` are now
instanced in their world scenes, and `env_ship_rib.glb` is instanced as wreck
debris. Trees, rocks and berry bush are still unwired; see `docs/STATE.md` §2.8
for the current art pass.
