# Blender asset generator

Headless Blender pipeline for Seed's low-poly model kit, item icons, and review
renders. Everything is generated from code, so assets can be regenerated or tuned
without a manual DCC session.

## Requirements

- Blender **5.2+** on `PATH` (`blender --version`)
- ImageMagick (`montage`) only for the icon contact sheet

## Run

```bash
blender -b --factory-startup --python tools/blender/build_seed_assets.py
montage assets/art/icons/*.png -tile 5x1 -geometry 256x256+8+8 \
  -background none docs/art/icon_sheet.png
```

The script rebuilds every asset from an empty scene:

| Output | Purpose |
|--------|---------|
| `assets/models/seed/*.glb` | game-ready glTF 2.0 props |
| `assets/art/icons/*.png` | 256 px transparent inventory icons |
| `docs/art/asset_kit_preview.png` | contact sheet for art review |
| `docs/art/ship_rib_preview.png` | hero render of the hull rib |
| `docs/art/icon_sheet.png` | icon strip (made by `montage`) |

## Conventions

Follows [`docs/art-direction.md`](../../docs/art-direction.md):

- 1 Blender unit = 1 metre; origin at ground contact.
- Front faces Blender **-Y**, which becomes glTF **+Z** after export.
- One mesh per asset, flat shaded, palette materials, no image textures.
- Triangle budgets: small props < 2k, trees < 1.5k, large wreck pieces < 3k.
- Materials come from the `PALETTE` table, so a colour change is one edit.

The exporter applies modifiers, triangulates, and writes a `.glb` with
`export_yup=True`. `.import` sidecars are generated by Godot and gitignored.

## Adding an asset

1. Write a `build_<name>()` function that returns `join(parts, "<category>_<name>")`.
2. Use the helpers: `box`, `cylinder`, `cone`, `sphere`, `tube`, `join`.
3. Pick colours from `PALETTE`; add a row there if the art direction gains a colour.
4. Register the builder in `main()` (export list) and, if it belongs on the
   contact sheet, in `render_contact_sheet()`.
5. Re-run the command above and check the triangle count printed to stdout.

Naming follows `docs/art-direction.md` §8:

- `prop_*` — built objects (pod, generator, shelter)
- `env_*` — natural / landmark pieces (tree, rock, berry bush, wreck rib)
- `icon_*` — inventory icons

## Ship kit

`build_ship_models.py` is a separate generator for the ship blockout. It writes
modular kit pieces, hero props, room shells and the ~1.28 km exterior hull under
`assets/models/ship/`. Scenes are assembled by
`tools/godot/generate_ship_scenes.py`:

```bash
blender -b --python tools/blender/build_ship_models.py -- all
python3 tools/godot/generate_ship_scenes.py
```

`tools/blender/render_ship_preview.py` produces a quick wide render of the exterior
model for review. See `docs/ship-structure.md` §9 for the current S0–S3 blockout
and its limits.

## Tuning

- Lighting, camera, and render samples live in `render_contact_sheet()` and
  `render_icons()`.
- Detection of broken framing: the contact sheet is rebuilt every run, so compare
  `docs/art/asset_kit_preview.png` after layout changes.
- All randomness is seeded (`random.Random(...)`) so output is repeatable.
