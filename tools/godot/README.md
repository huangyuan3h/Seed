# Godot scene assembly

`generate_ship_scenes.py` writes the ship blockout scenes from the generated
glTF assets. It is a plain Python script (no Godot dependency); re-run it after
changing the Blender generator or the room/prop layout.

```bash
blender -b --python tools/blender/build_ship_models.py -- all
python3 tools/godot/generate_ship_scenes.py
```

Outputs:

```
scenes/ship/sections/cryo_bay.tscn
scenes/ship/sections/med_bay.tscn
scenes/ship/sections/spine_corridor.tscn
scenes/ship/ship_interior.tscn
scenes/ship/ship_preview.tscn
scenes/ship/ship_exterior.tscn
scenes/ship/ship_exterior_preview.tscn
```

The generator is the source of truth for repeated placement (24 cryo pods,
corridor dressing, exterior collision boxes). Hand-edit the generator, not the
generated `.tscn`, when adding another pod row or room.

The `.import` sidecars are generated by Godot and gitignored. `tools/godot/`
also contains `verify_generated_models.gd`, used by the art pass to sanity-check
the seed kit; it is independent of the ship generator.
